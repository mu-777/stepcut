# プロジェクトファイル仕様(version 1)

決定記録は [decisions/20261029-project-format.md](decisions/20261029-project-format.md)。機械向けの JSON Schema は [project.schema.json](project.schema.json)(`src/core/schema.ts` から生成)。検証は `stepcut validate <file> [--json]`(AI-04)。

人と AI の両方が直接編集する前提の仕様。この文書だけを読めば、ステップの追加・変更ができることを目標にする(要件 9 章)。

## 1. 基本ルール

| 項目 | ルール |
|---|---|
| 形式 | UTF-8 の JSON。拡張子は `.stepcut.json` |
| 時間の単位 | 秒(小数可、ミリ秒まで有効) |
| ステップ内の時刻 | **ステップ内の出力時刻**。ステップの先頭が 0。保持や早送りを反映した後の時刻 |
| ソース内の時刻 | ステップの `segments` の `in` / `out` だけはソース(録画ファイル)の時刻 |
| 映像側の座標 | ソース映像のピクセル。左上が原点。ズーム・ポインター・図形が使う |
| 画面側の座標 | 出力画面に対する割合(0〜1)。左上が原点。出力解像度を変えても位置が変わらない |
| 文字サイズ | 出力の高さ 1080 を基準にした px。720p で出力すると 2/3 倍で描画する |
| 色 | `#RRGGBB` または `#RRGGBBAA` |
| 省略 | 省略できる項目は既定値またはプロジェクト共通設定を使う(STY-02) |
| 知らない項目 | 検証エラーにする(打ち間違いを見逃さないため) |
| 配列の順序 | `steps` の順が出力順 |

## 2. 全体構造

```json
{
  "format": "stepcut.project",
  "version": 1,
  "output": { ... },
  "layout": { ... },
  "styles": { ... },
  "speech": { ... },
  "audio": { ... },
  "dictionary": [ ... ],
  "sources": [ ... ],
  "steps": [ ... ]
}
```

| キー | 必須 | 内容 |
|---|---|---|
| `format` | ○ | 固定値 `"stepcut.project"` |
| `version` | ○ | 仕様の版。この文書は `1` |
| `output` | | 出力設定(OUT) |
| `layout` | | レイアウト(LAY) |
| `styles` | | 見た目の共通設定(STY) |
| `speech` | | 読み上げの共通設定(TTS) |
| `audio` | | 音量の共通設定(AUD) |
| `dictionary` | | 読みの辞書(TTS-06、プロジェクト単位) |
| `sources` | ○ | 録画ファイル(PRJ) |
| `steps` | ○ | ステップの並び(STP) |

## 3. 各項目

### 3.1 output

| キー | 既定 | 内容 |
|---|---|---|
| `width` / `height` | 1920 / 1080 | 出力解像度(偶数) |
| `fps` | 30 | `30` または `60` |
| `quality` | `"high"` | `"low"` / `"medium"` / `"high"` |
| `srt` | `false` | mp4 と同時に SRT を書き出す |

### 3.2 layout

| キー | 既定 | 内容 |
|---|---|---|
| `background` | `{ "image": "preset:default" }` | 背景。下の 3 種類のどれか |
| `margin` | `{ "top": 0.04, "right": 0.0225, "bottom": 0.2, "left": 0.0225 }` | 録画の周りの余白。`top` / `bottom` は出力の高さ、`left` / `right` は出力の幅に対する割合。すべて 0 なら全画面 |
| `fit` | `"contain"` | 余白の内側への録画の置き方。`"contain"` は縦横比を保って全体を収める(すき間には背景が見える)、`"cover"` は余白の内側いっぱいに描き、はみ出す録画の端を切り取る |
| `shadow` | `true` | 録画のドロップシャドウ |

`margin` / `fit` / `shadow` はステップの `layout` で上書きできる(3.7)。

旧い書き方(`mode` / `bandHeight` / 数値の `margin` / `video`)は読み込み時に `margin` へ直す。`"mode": "full"` は余白 0、`"band"` は上・左・右に旧 `margin`、下に `bandHeight` の余白になる。

`background` の書き方:

| 種類 | 例 | 内容 |
|---|---|---|
| 単色 | `"#1E1F22"` | 色 |
| グラデーション | `{ "gradient": { "angle": 135, "colors": ["#1E2A5A", "#6A3093"] } }` | 線形。`angle` は CSS と同じ向き(0 = 下から上、90 = 左から右。既定 180)。`colors` は 2〜4 色を等間隔に置く |
| 画像 | `{ "image": "preset:mint" }` / `{ "image": "bg/back.png" }` | `preset:` で始まれば同梱のプリセット(`default` `sunset` `mint` `ocean` `graphite` `paper`)。それ以外は画像ファイルのパス(素材と同じ規則で相対・絶対。PRJ-05)。出力いっぱいに縦横比を保って敷き詰め、はみ出しは切る |

### 3.3 styles

プロジェクト共通の見た目。各要素の `style` に同名のキーを書くと、その要素だけ上書きする。

テロップの位置は、ステップの `caption.position` / `width` → `styles.caption.position` / `width` → 既定の順に決まる。どこにも書かなければ、録画の下の余白にテロップが収まるならその中央、収まらなければ画面の高さ 88% の位置に置く。

| キー | 内容 |
|---|---|
| `caption` | `font`(既定 `"Yu Gothic UI"`)、`size`(48)、`color`(`"#FFFFFF"`)、`lineHeight`(1.4)、`align`(`"center"` / `"left"`)、`background`(文字の背景の箱の色。既定 `"#00000000"` = 箱なし。箱を付けるときは `"#000000AA"` など。旧い書き方の `"auto"` は箱なしとして扱う)。プロジェクト共通の `styles.caption` には、テロップの置き方の既定 `position`(中心、画面側座標)と `width`(テロップの幅。出力の幅に対する割合で、文はこの幅で折り返す。既定 0.8)も書ける |
| `pointer` | `preset`(見た目。`"arrow"` = 矢印のカーソル(既定)、`"dot"` = 丸、`"ring"` = 輪、`"highlighter"` = 蛍光ペン(動きに沿って線を引く))、`size`(カーソル・丸・輪・画像の大きさ。出力の高さ 1080 を基準にした px。ズームしても変わらない。48)、`image`(ユーザーの画像ファイル。書くと `preset` の代わりに使い、画像の左上を指す点にする。パスは素材と同じ規則)、`color`(丸・輪・蛍光ペンの色。既定は丸 `"#FF3B30"`(半透明で描く)・輪 `"#FFD60A"`・蛍光ペン `"#FFEB3B"`)、`width`(蛍光ペンの線の太さ。ソースのピクセル。24)、`opacity`(蛍光ペンの不透明度。0.4) |
| `rect` | 四角。`stroke`(線の色。`"#FF3B30"`)、`strokeWidth`(ソースのピクセル。0 で線なし。6)、`fill`(塗りの色。`"#FF3B30"`)、`fillOpacity`(塗りの不透明度。0 で枠だけ。0)、`radius`(角の丸み。ソースのピクセル。8) |
| `arrow` | 矢印。`color`(`"#FF3B30"`)、`width`(軸の太さ。ソースのピクセル。12)、`head`(矢じりの長さ = 太さ × `head`。幅はその 1.2 倍。3) |
| `text` | 自由に置く文字。`font`(テロップと同じ既定)、`size`(ソースのピクセル。ズームに合わせて大きくなる。40)、`color`(`"#FFFFFF"`)、`align`(`"left"` / `"center"` / `"right"`。`"center"`)、`background`(枠の塗り。`"#000000B3"`。透明 `"#RRGGBB00"` なら塗らない) |

### 3.4 speech と audio

```json
"speech": { "engine": "os", "voice": null, "params": { "rate": 1.0 }, "startOffset": 1 },
"audio":  { "source": { "enabled": true, "volume": 1.0, "keepPitch": true }, "speech": { "volume": 1.0 } }
```

- `engine`: 読み上げエンジンの名前。`"os"`(既定)が内蔵の OS 標準音声、`"voicevox"` が VOICEVOX 互換エンジン、`"azure"` が Azure AI Speech。`voicevox` / `azure` は、プロジェクトを開いたパソコンのアプリの設定で有効にしていなければ OS 標準の声で代わりに読む(TTS-14)。鍵や接続先はプロジェクトには書かない(アプリの設定にある)
- `voice`: エンジンが返す声の ID。`null` はエンジンの既定の声(VOICEVOX は声のスタイル ID の数字の文字列、Azure は `ja-JP-NanamiNeural` のような名前)
- `params`: エンジンが返すパラメータ一覧(TTS-04)のうち、変える項目だけを書く
- `startOffset`: `start` を書いていない最初の読み上げを、ステップの頭から何秒後に読み始めるか。既定 1。全体だけに書ける(ステップでは上書きできない。ずらすときは読み上げの `start` を書く)
- `volume`: 0〜2(1 が等倍)
- `source.enabled`: 元の音声を鳴らすか。全体で `false` にすると、どのステップも鳴らさない(ステップ側の `true` より優先。タイムラインの映像の段の見出しのボタン)。全体で消していなければステップの設定に従い、既定は通常ステップで `true`、早送りステップで `false`(早送りステップはステップ側で `true` にしたときだけ鳴る)
- `source.keepPitch`: 早送りステップで音の高さを保つか。既定 `true`。`false` なら速度に合わせて高くなる
- `startOffset` 以外はステップ側で上書きできる

### 3.5 dictionary

```json
"dictionary": [ { "from": "GUI", "to": "ジーユーアイ" } ]
```

読み上げ文だけに適用し、テロップは変えない。上から順に置き換える。

### 3.6 sources

```json
"sources": [ { "id": "rec1", "path": "rec/2026-10-29.mp4" }, { "id": "title", "path": "img/title.png" } ]
```

素材は録画(mp4)か画像(拡張子 `png` / `jpg` / `jpeg` / `webp`)。種類は `path` の拡張子で決まる。画像はどの時刻でも同じ 1 枚(音なし)で、それを使うステップの区間は長さだけを表す(`out − in` 秒。アプリで足すと `segments: [{ "in": 0, "out": 3 }]`)。座標(ズーム・オブジェクト)は画像のピクセル。

| キー | 必須 | 内容 |
|---|---|---|
| `id` | ○ | ステップから参照する名前。英数字・`-`・`_` |
| `path` | ○ | プロジェクトファイルと同じフォルダかその下なら相対パス、それ以外は絶対パス(PRJ-05) |

### 3.7 steps

```json
{
  "id": "login",
  "source": "rec1",
  "segments": [ { "in": 12.0, "out": 18.5 } ],
  "speed": 1,
  "caption": { "text": "右上の「ログイン」を押します" },
  "speech": { "text": "右上のログインを押します。" },
  "audio": { "source": { "enabled": false } },
  "holds": [ { "at": 2.0, "duration": 1.5 } ],
  "zooms": [],
  "pointers": [],
  "shapes": []
}
```

| キー | 必須 | 内容 |
|---|---|---|
| `id` | ○ | ステップの名前。プロジェクト内で重複不可。AI への指示や差分で使う。画面には出さず、画面ではステップを時間の順の番号(ステップ N)で呼ぶ |
| `source` | ○ | `sources` の `id` |
| `segments` | ○ | 録画の区間(`in` 〜 `out`。ソースの時刻)の配列。区間が 1 つでも配列で書く。2 つ以上なら並び順に続けて再生する(間を飛ばしても、手前に戻ってもよい。ステップをまとめるとできる。STP-09)。速度(`speed`)はすべての区間に同じものを掛ける。素材が画像なら区間 1 つで、長さだけを表す(3.6) |
| `speed` | | `1` なら通常ステップ、`1` より大きいと早送りステップ(STP-07)。既定 1 |
| `layout` | | このステップだけの録画の枠。`margin` / `fit` / `shadow`(形と意味は 3.2 と同じ)のうち書いた項目だけ、全体の `layout` を上書きする。背景は書けない(全体だけ) |
| `fadeIn` / `fadeOut` | | ステップの始まりで黒から現れる・終わりで黒へ消える長さ(秒、0 より大)。背景・録画・テロップと音声(元の音声・読み上げ)をまとめて掛ける。省略するとフェードなし(STP-11) |
| `caption` | | テロップ。`text`(改行は `\n`)、`start`(既定 0)、`end`(既定 `null` = ステップの終わりまで)、`position`(中心の位置。画面側座標。`styles.caption.position` を上書きする)、`width`(テロップの幅。出力の幅に対する割合。`styles.caption.width` を上書きする)、`style` |
| `speech` | | 読み上げ。書かなければ読まない。1 つならオブジェクト、複数なら配列(STP-08)。各項目は `text`(読む文。最初の 1 つだけ、省略するとテロップの文を読む)、`start`(読み始めるステップ内の出力時刻。省略すると最初は全体の `speech.startOffset`(既定 1 秒)、2 つ目からは前の読み上げの直後。保持を除いた映像の長さを超えられない)、`voice`、`params`(2 つ目からは省略すると最初の読み上げに合わせる) |
| `audio` | | 音量の上書き。形は 3.4 と同じ |
| `holds` | | 保持(TIM-02)。`at` の出力時刻で映像を止め、`duration` 秒保持する |
| `zooms` | | ズーム(ZM) |
| `pointers` | | 擬似ポインター。蛍光ペンも見た目が蛍光ペンのポインター(ANN) |
| `shapes` | | 図形(四角・矢印・文字。四角には画像を入れられる。ANN-10〜14) |

#### ズーム

```json
{ "start": 1.0, "end": 4.0, "keys": [ { "t": 1.0, "rect": { "x": 640, "y": 300, "w": 800, "h": 450 } } ] }
{ "start": 1.0, "end": 4.0, "hold": false, "keys": [
  { "t": 1.0, "rect": { "x": 640, "y": 0,   "w": 800, "h": 450 } },
  { "t": 2.0, "rect": { "x": 640, "y": 300, "w": 800, "h": 450 } },
  { "t": 4.0, "rect": { "x": 640, "y": 600, "w": 800, "h": 450 } } ] }
```

- `start` 〜 `end` は拡大したまま保つ区間。拡大の動きは `start` の手前、縮小の動きは `end` の後ろで行う(ステップの外にはみ出す分は切り詰める)
- `keys` はズームの枠(キーフレーム)。`t` はステップ内の出力時刻で、`start` 〜 `end` の中に、早い順に同じ時刻を重ねずに並べる。`rect` は映像側座標の範囲。枠が 1 つなら動かない。2 つ以上なら枠と枠の間を一定の速さで移る(文字を追うなど)。最初の枠より前は最初の枠、最後の枠より後は最後の枠のまま
- 既定では枠どおりの範囲だけを映す。録画を描く領域は枠の縦横比になり、余白の内側に収めて中央に置く。テロップの位置はズームの影響を受けない
- `keepAspect`(既定 `false`)が `true` なら録画の縦横比を保つ。枠と縦横比が違うときは、中心を保って上下か左右を広げて表示する
- `hold`(既定 `true`)のとき、`start` から `end` まで映像を止める。`holds` に `{ "at": start, "duration": end - start }` を書いたのと同じ扱いになる(保持とズーム中の静止は同じ機能)。`false` なら映像を流し続ける。`"transition"` なら拡大・縮小の動きの間だけ止める: `{ "at": start - transition, "duration": transition }`(ステップの頭より前には出さない)と `{ "at": end, "duration": transition }` の 2 つの保持と同じ扱い。このとき `transition` を省略すると 0.8 秒(倍率から決める既定の式は使わない)
- `transition` は拡大・縮小の動きにかける秒数。省略すると倍率から決める(0.6 + 0.55 × ln(倍率) 秒。2 倍で約 1 秒)。`0` なら動きなしで切り替える
- 前のズームの `end` から次のズームの `start` まで 1.5 秒未満なら、いったん戻らずに次の範囲へ移る。隣のステップどうしでも、同じ録画(`source` が同じ)なら同じ規則で続ける。前のステップの最後のズームの `end` からステップの終わりまでと、次のステップの頭から最初のズームの `start` までの合計が 1.5 秒未満なら、境界で戻らずに次の範囲へ移る(ファイルにはなにも書かない。並べ替え・削除で隣が変われば続くかも変わる)

#### ポインター(蛍光ペンを含む)

```json
{ "mode": "line", "path": [ { "t": 1.0, "x": 300, "y": 520 }, { "t": 1.8, "x": 900, "y": 520 } ],
  "end": 3.0, "enter": "fade", "exit": "fade", "click": true, "style": { "preset": "dot" } }
{ "mode": "line", "path": [ { "t": 1.0, "x": 520, "y": 410 }, { "t": 1.6, "x": 1100, "y": 410 } ],
  "style": { "preset": "highlighter", "color": "#7CFC00" } }
```

| キー | 内容 |
|---|---|
| `mode` | `"line"`(直線。点は 2 つ)または `"freehand"`(点は 2 つ以上) |
| `path` | 時刻付きの点(映像側座標)。早い順に並べる。ポインターは点の間を移動し(直線はゆっくり動き出して止まる、フリーハンドは一定の速さ)、見た目が蛍光ペンなら点に沿って線を引いていく(引いた線は `end` まで残る) |
| `end` | 消える時刻。既定はステップの終わり。映像より後を書くと、その分ステップを伸ばす(4 章)。表示開始は `path` の最初の点の時刻 |
| `enter` / `exit` | 現れ方・消え方(ANN-09)。`"none"` / `"fade"` / `"flash"` か、長さ・点滅の回数も書く形 `{ "type": "flash", "duration": 1.0, "count": 5 }`(`duration` は秒、`count` は点滅の回数。省略した項目は既定)。既定 `"none"` |
| `click` | `true` なら最後の点に着いたときにクリックの波紋を出す(0.5 秒。蛍光ペンには出さない)。既定 `false` |
| `style` | `styles.pointer` の上書き |

`fade` は既定 0.3 秒かけて現れる・消える。`flash` は既定 0.6 秒の間に 3 回、均等に点滅して現れる・消える(`duration` を出ている間と同じにすれば、出ている間ずっと点滅する)。どちらも出ている間より長くはしない。現れ方と消え方が重なる時刻は、暗い方をとる。

旧い書き方の `highlights`(蛍光ペン)と `styles.highlighter` は、読み込むときに `"preset": "highlighter"` のポインターへ直す(`styles.highlighter` の値は各ポインターの `style` に書く)。

#### 図形

```json
{ "type": "rect", "start": 1.0, "end": 4.0, "rect": { "x": 600, "y": 300, "w": 320, "h": 120 }, "style": { "fillOpacity": 0.2 } }
{ "type": "arrow", "start": 1.0, "from": { "x": 200, "y": 600 }, "to": { "x": 600, "y": 360 }, "enter": "flash" }
{ "type": "text", "start": 1.0, "rect": { "x": 100, "y": 650, "w": 400, "h": 80 }, "text": "ここを押す" }
{ "type": "rect", "start": 0, "rect": { "x": 1600, "y": 20, "w": 280, "h": 90 }, "image": "img/logo.png", "style": { "strokeWidth": 0 } }
{ "type": "text", "start": 0, "anchor": "screen", "rect": { "x": 40, "y": 940, "w": 600, "h": 100 }, "text": "手順 1: ログイン" }
```

| キー | 内容 |
|---|---|
| `type` | `"rect"`(四角)・`"arrow"`(矢印)・`"text"`(文字) |
| `start` / `end` | 出ている間(ステップ内の出力時刻)。`end` の既定はステップの終わり。映像より後を書くと、その分ステップを伸ばす(4 章) |
| `enter` / `exit` | ポインターと同じ |
| `anchor` | 座標の基準。省略すると映像側(ソースのピクセル。ズームに追従し、録画の領域の中だけに描く)。`"screen"` は画面側で、出力の高さ 1080 を基準にした px(1920×1080 の出力ならそのままのピクセル。左上が原点)。ズームしても動かず、背景や録画と背景にまたがる位置にも描く。`rect` / `from` / `to` と `style` の太さ・角の丸み・文字の大きさもこの単位になる |
| `rect` | 四角・文字の枠(`anchor` の座標)。文字は枠の幅で折り返し、上下の中央に置く |
| `from` / `to` | 矢印の始点と先端(`anchor` の座標) |
| `text` | 文字の文(改行は `\n`) |
| `image` | 四角だけ。中に描く画像ファイルのパス(素材と同じ規則で相対・絶対。PRJ-05)。枠いっぱいに描き(縦横比は枠に合わせる)、角の丸みで切る。塗り → 画像 → 線の順に描くので、線は画像の枠になり、透明な所には塗りが見える |
| `style` | `styles.rect` / `styles.arrow` / `styles.text` の上書き |

描く順(奥から): 録画 → 見た目が蛍光ペンのポインター → 図形(`shapes` の順。後ろほど手前) → ほかのポインター → テロップ。ポインターと映像側の図形は録画の領域の外には描かない(余白にははみ出さない)。

## 4. ステップの長さと時刻の対応

ステップの出力上の長さは次で決まる。

1. 映像の長さ = 各区間の (`out` − `in`) の合計 ÷ `speed`
2. 保持の合計を足す(`holds` と、`hold` が `true` か `"transition"` のズーム)
3. 読み上げの終わり(最後に終わる読み上げの開始 + 長さ)か、`end` を書いたポインター・図形の `end` がそれより後なら、差の分だけ最終フレームを保持する(TIM-03)。前ならそのまま(TIM-04)

出力時刻 t に表示するソースのフレーム: t より前に終わった保持の長さを t から引き、保持の途中ならその保持の開始時刻にそろえ、`speed` を掛けて、区間を並び順にたどった位置(区間の切れ目ちょうどは次の区間の `in`)にする。その時刻の直前のフレームを使う(フレームレートが一定でないソースでも同じ規則で扱う。U-07)。

保持どうし、ズームどうしは重ねられない(検証エラー)。

## 5. 音声

- 元の音声は、映像が動いている区間だけ鳴らす。保持の間は止まる
- 早送りステップ(`speed` > 1)では、既定で元の音声を鳴らさない(速度を変えた音は聞き取りにくいため。仮決め)。ステップの `audio.source.enabled` を `true` にすると鳴らし、`audio.source.keepPitch`(既定 `true`)なら音の高さを保ったまま縮め、`false` なら速く再生する(高くなる)
- `fadeIn` / `fadeOut` のある区間は、元の音声と読み上げをまとめて映像と同じ割合で小さくする
- 読み上げはそれぞれの `start`(省略時は 3.4 の `speech` の規則)から鳴らし、元の音声と重ねる
