# 概念と用語集

このアプリの考え方(データモデル・時間・座標・処理の流れ)と用語をまとめた資料。AI がコードやプロジェクトファイルを扱う前に読む前提で書く。

細かい値・キーの一覧は [project-format.md](project-format.md)、要件の正は [requirements.md](requirements.md)、決定の理由は [decisions/](decisions/) を見る。ここは概念の地図に徹し、値の重複はなるべく避ける。

## 1. 何をするアプリか

- 入力: 別ツールで録った画面録画(mp4)。表紙や補足に画像(png・jpg・webp)も素材にできる
- 出力: 手順書動画(mp4)と、必要なら字幕(SRT)
- 作業: 録画を**ステップ**に切り分け、各ステップに**テロップ・読み上げ・ズーム・保持・オブジェクト**(ポインター・図形)を付ける
- 保存: 編集内容は JSON の**プロジェクトファイル**。人も AI も直接編集する
- 制約: 全機能オフライン、ランニングコストゼロ、機能は最小限(要件 C1・C7)

対象外(要件 3.2): 画面録画そのもの、Web カメラ、自動ズーム、Web 版・クラウド連携、フェード・フラッシュ以外のアニメーション。

## 2. 全体の流れ

```
録画(mp4) ──参照──▶ プロジェクトファイル(.sanno.json)
                      │  sources: 録画の一覧
                      │  steps:   録画の区間 + 付ける要素
                      ▼
            ┌─ 編集画面(Electron) ─ プレビュー ─┐
            │   同じ合成処理(compositor/audio)  │ ← OUT-06: 見た目を一致させる
            └─ 書き出し(UI / CLI) ─ mp4・SRT ──┘
                      ▲
   AI・人がテキストで編集 → アプリが外部変更を検知して再読み込み
```

## 3. データモデル

### 3.1 プロジェクト

1 本の出力動画 = 1 つのプロジェクトファイル。主な中身:

| キー | 概念 | 単位 |
|---|---|---|
| `sources` | 素材(録画・画像)の一覧(id とパス)。画像はどの時刻も同じ 1 枚で、ステップの `in` / `out` は長さだけを表す | プロジェクト |
| `steps` | ステップの並び。配列の順が出力順 | プロジェクト |
| `output` | 解像度・fps・画質・SRT の有無 | プロジェクト |
| `layout` | 背景・余白・録画の収め方・影 | プロジェクト(余白・収め方・影はステップで上書き可) |
| `styles` | テロップ等の見た目の共通設定 | プロジェクト(ステップで上書き可) |
| `speech` / `audio` | 読み上げエンジン・声 / 音量 | プロジェクト(ステップで上書き可) |
| `dictionary` | 読みの辞書 | プロジェクト |

### 3.2 ステップ

出力動画を構成する単位(手順 1、手順 2…に対応)。**ソースの区間を参照するだけ**で、録画ファイルは切らない。

- 1 本の録画を複数ステップに切り分ける。同じ区間を複数ステップで再利用してもよい
- どのステップにも含まれない区間は出力されない(= カット)
- 種類は 2 つ: **通常**(`speed` = 1)と**早送り**(`speed` > 1)
- 操作: 分割(後半を新ステップにするか捨てる)・並べ替え・複製・削除・結合(同じ録画の続いた区間で速度が同じとき)

汎用の多トラック編集は採らない(決定 [20261026-step-based-model](decisions/20261026-step-based-model.md))。タイムラインは見せ方であり、データはステップ単位のまま。

### 3.3 継承(共通設定 → 個別の上書き)

見た目・読み上げ・音量は「既定値 ← プロジェクト共通 ← ステップ(要素)の上書き」の順で決まる(STY-02)。

- schema(`src/core/schema.ts`)は既定値を埋めない。既定値の解決は `src/core/defaults.ts`
- 理由: 保存時に、人や AI が書いていない項目を増やさないため

## 4. 時間のモデル

### 4.1 2 つの時刻

| 時刻 | 使う場所 | 基準 |
|---|---|---|
| ソース時刻 | ステップの `in` / `out` だけ | 録画ファイルの先頭が 0 |
| ステップ内の出力時刻 | それ以外すべて(テロップ・読み上げ・ズーム・保持・ポインター・図形) | ステップの先頭が 0。保持・早送りを反映した後の時刻 |

出力時刻で持つ理由: 保持で尺が伸びても、後ろの要素の位置がずれない。

### 4.2 ステップの長さ

1. 映像の長さ = (`out` − `in`) ÷ `speed`
2. 保持の合計を足す
3. 読み上げが映像より後に終わるなら、最終フレームを自動で保持して尺を合わせる(**自動保持**)。映像の方が長ければそのまま再生する

出力時刻 → ソース時刻の変換は `src/core/timeline.ts`(仕様は project-format.md 4 章)。

### 4.3 保持

映像をその時点のフレームで止め、指定秒数表示し続けること。

- 明示した保持(`holds`)と、ズーム中の静止(`hold: true` のズーム。既定)は**同じ機能**として扱う
- 保持中は元の音声も止まる。読み上げは止まらない

## 5. 空間のモデル

### 5.1 画面の構成

```
┌──────────── 出力画面(output.width × height)───────────┐
│ 背景(色 / グラデーション / 画像)                         │
│   ┌──────── 録画領域(余白の内側)────────┐              │
│   │  録画(contain: 全体を収める          │ ← 影          │
│   │        cover:  はみ出しを切る)        │              │
│   └──────────────────────────────────┘              │
│          テロップ(既定: 録画の下の余白の中央)             │
└──────────────────────────────────────────────┘
```

- **余白**: 録画の上下左右の空き。全体の値をステップごとに上書きできる(`steps[].layout`)。すべて 0 なら全画面。既定は下を広く取り、そこにテロップを置く
- プレビュー上で録画の枠を動かすと、再生位置のステップの余白の値が変わる(決定 [20261031-margin-layout](decisions/20261031-margin-layout.md))

### 5.2 2 つの座標系

| 座標系 | 単位 | ズームの影響 | 使う要素 |
|---|---|---|---|
| 映像側 | ソース映像のピクセル。左上原点 | 追従する | ズーム範囲・ポインター・図形 |
| 画面側 | 出力画面に対する割合(0〜1)。左上原点 | 受けない | テロップの位置 |

要素の種類ごとに固定し、ユーザーには選ばせない(決定 [20261026-coordinate-system](decisions/20261026-coordinate-system.md))。文字サイズは出力の高さ 1080 を基準にした px。

## 6. ステップに付ける要素

| 要素 | 概念 | 時刻 | 座標 | 状態 |
|---|---|---|---|---|
| テロップ | 画面に出す文字。1 ステップ 1 つ。既定はステップの全期間 | 出力時刻 | 画面側 | M1 |
| 読み上げ | 文を音声合成して鳴らす。1 ステップに複数可。最初の 1 つは既定でテロップの文を読む | 出力時刻(開始のみ) | — | M1 |
| ズーム | 映像の一部へ拡大する | 出力時刻 | 映像側 | M1 |
| 保持 | 映像を止める | 出力時刻 | — | M1 |
| ポインター | 後から付ける擬似カーソル。録画のカーソルは使わない | 出力時刻 | 映像側 | M2 |
| 蛍光ペン | 線を引いて強調する。見た目が蛍光ペンのポインター | 出力時刻 | 映像側 | M2 |
| 図形 | 四角(画像を入れられる)・矢印・文字 | 出力時刻 | 映像側(図形ごとに画面側も選べる) | M2 |

### 6.1 ズーム

(決定 [20261031-zoom-model](decisions/20261031-zoom-model.md))

- `start`〜`end` は**拡大したまま保つ区間**。拡大の動きはその手前、縮小の動きはその後ろ
- 範囲は枠(キーフレーム)`keys: [{ t, rect }]` で決める。既定は枠どおりの範囲を映す(`keepAspect: true` なら録画の縦横比に広げる)
- 動きの時間は既定で倍率から自動(0.6 + 0.55 × ln(倍率) 秒)
- 枠が 2 つ以上なら、枠と枠の間を一定の速さで移る
- 間が 1.5 秒未満のズームどうしは、戻らずに次の範囲へ移る
- 自動ズームはしない

### 6.2 読み上げ

- エンジンは差し替え可能。内蔵は OS 標準音声(Windows: WinRT SpeechSynthesizer、Mac: `say`、それ以外は無音で代替)。VOICEVOX 互換エンジンと Azure AI Speech はアプリに組み込んであるが、ユーザーがアプリの設定で規約・費用の確認に同意して有効にしたときだけ使える(エンジン・声・鍵はユーザーが用意する)。そのほかは**プラグイン**で追加する(別プロセス)
- エンジンの入出力: 文章・声・パラメータ → wav と長さ
- **読みの辞書**: エンジンに渡す前に文字列を置き換える。テロップの表示は変えない
- 生成音声はキャッシュする(エンジン・バージョン・声・パラメータ・辞書適用後の文が一致すれば再利用)

### 6.3 音声の合成

- 元の音声: 映像が動いている区間だけ鳴らす。保持中・早送りステップでは鳴らさない(後者は仮決め)
- 読み上げ: 元の音声と重ねる
- 音量: プロジェクト共通 + ステップの上書き

## 7. プレビューと書き出し

- 1 フレームの合成(`src/renderer/src/compositor.ts`)と音声の合成(`audio.ts`)をプレビューと書き出しで共用する(OUT-06)
- 書き出し: 映像 H.264(WebCodecs。ハードウェア優先、なければソフトウェア + 警告)、音声 AAC(なければ Opus + 警告)。GPL の x264 等は使わない(決定 [20261026-encoder](decisions/20261026-encoder.md))
- プレビューの再生速度・拡大表示は書き出しに影響しない

## 8. AI との往復

1. AI がプロジェクトファイルを編集する(仕様: project-format.md、JSON Schema: project.schema.json)
2. `screen-annotator validate <file> --json` で検証する(知らないキーはエラー。id 参照・時刻の重なりも調べる)
3. 開いているアプリは外部変更を検知して再読み込みする。アプリ側に未保存の変更があれば、どちらを採るか人に確認する
4. `screen-annotator export <file> --json` で UI なしに書き出す

素材のパスは、プロジェクトと同じフォルダかその下なら相対、それ以外は絶対で保存する(区切りは常に `/`)。

## 9. コードの構成

| 場所 | プロセス | 役割 |
|---|---|---|
| `src/core/` | 共通(純粋関数) | schema・既定値・検証・旧形式の変換・時刻変換・レイアウト計算・テロップ折り返し・ステップ編集 |

## 10. 用語集

| 用語 | 定義 | JSON / コード |
|---|---|---|
| プロジェクト | 1 本の出力動画の編集内容。JSON 1 ファイル | `.sanno.json`、`Project` |
| ソース(素材、録画) | 取り込んだ録画ファイル(mp4) | `sources[]` |
| ステップ | 出力動画の構成単位。ソースの区間と付ける要素を持つ | `steps[]`、`Step` |
| In / Out | ステップが使うソースの区間の始まりと終わり(ソース時刻) | `in` / `out` |
| カット | どのステップにも含まれず出力されない区間 | — |
| 通常ステップ | 等速で再生するステップ | `speed: 1` |
| 早送りステップ | 指定した速度で再生するステップ。元の音声は鳴らさない | `speed` > 1 |
| 分割 | ステップを出力時刻で 2 つに分ける。後半は新ステップか捨てる | `src/core/edit.ts` |
| 結合(まとめる) | 隣り合うステップを 1 つにする。同じ録画の続いた区間で同じ速度のときだけ | 同上 |
| ソース時刻 | 録画ファイル内の時刻 | `in` / `out` |
| ステップ内の出力時刻 | ステップ先頭を 0 とし、保持・早送りを反映した後の時刻 | `start` / `end` / `at` / `t` |
| 保持(ホールド) | 映像を止め、そのフレームを表示し続けること | `holds[]`、`Hold` |
| 自動保持 | 読み上げが映像より長いとき、最終フレームを自動で保持すること | 計算で決まる(JSON にはない) |
| ズーム中の静止 | ズームの間、映像を止めること。保持と同じ扱い | `zooms[].hold`(既定 true) |
| 出力画面 | 書き出す動画の画面全体 | `output.width` / `height` |
| 余白 | 録画の上下左右の空き。上下は出力の高さ、左右は幅に対する割合 | `layout.margin` |
| 全画面 | 余白がすべて 0 の状態 | — |
| 録画領域 | 余白の内側。録画を描く場所 | `src/core/layout.ts` |
| 収め方 | 録画領域への収め方。全体を収めるか、端を切って埋めるか | `layout.fit`(`contain` / `cover`) |
| 背景 | 録画の後ろに描くもの。単色・グラデーション・画像 | `layout.background` |
| プリセット画像 | コードで描く同梱の背景画像 | `preset:<名前>` |
| ドロップシャドウ | 録画に付ける影 | `layout.shadow` |
| 映像側座標 | ソース映像のピクセル座標。ズームに追従する | `keys[].rect`、`path[].x/y` |
| 画面側座標 | 出力画面に対する割合(0〜1)。ズームの影響を受けない | `caption.position` |
| テロップ | 画面に出す文字。SRT にも出せる | `caption` |
| テロップの幅 | テロップの幅(出力の幅に対する割合)。文がこの幅を超えると折り返す。画面では「幅」 | `caption.width` |
| 文字の背景の箱 | テロップの後ろの帯。既定はなし | `styles.caption.background` |
| 読み上げ | 文を音声合成して鳴らすこと | `speech`(オブジェクトか配列) |
| 読み上げエンジン | 文から音声を作る仕組み。内蔵の OS 標準音声とプラグイン | `speech.engine`(`"os"` が内蔵) |
| 声 | エンジンが返す声の ID | `speech.voice` |
| 読みの辞書 | 誤読する語をエンジンに渡す前に置き換える一覧 | `dictionary[]` |
| プラグイン | 別プロセスで動く追加の読み上げエンジン。なくても全機能が動く | `src/main/tts/engine.ts` のインターフェース |
| 試聴 | 読み上げだけを鳴らして確かめること | UI のみ |
| 元の音声 | 録画に入っている音声 | `audio.source` |
| ズーム | 映像の一部へ拡大すること | `zooms[]`、`Zoom` |
| ズームの枠(キーフレーム) | ある時刻に映す範囲(映像側座標)。複数あれば間を一定の速さで移る | `keys[].t` / `keys[].rect` |
| 録画の縦横比を保つ | 枠を録画の縦横比に広げて映す(既定は枠どおり) | `keepAspect` |
| 動きの時間 | 拡大・縮小の動きにかける秒数 | `transition` |
| ポインター(擬似ポインター) | 後から付けるカーソル | `pointers[]` |
| 蛍光ペン | 線を引いて強調するもの。見た目が蛍光ペンのポインター(旧 `highlights[]` は読み込み時に直す) | `pointers[].style.preset = "highlighter"` |
| 図形 | 四角(画像を入れられる)・矢印・文字 | `shapes[]`(`type`) |
| オブジェクト | ポインター・図形をまとめた画面上の呼び名(タイムラインの段・設定パネルの欄) | — |
| 直線 / フリーハンド | ポインターの 2 つのモード | `mode`(`line` / `freehand`) |
| フェード / フラッシュ | オブジェクトの出入りの効果 | `enter` / `exit` |
| 共通設定 / 上書き | プロジェクト全体の設定と、ステップ・要素ごとの個別設定 | `styles` と各要素の `style` |
| プレビュー | 編集画面で合成結果を表示する部分。書き出しと同じ描画処理 | `preview.tsx`、`player.ts` |
| タイムライン | 固定トラック(映像・テロップ・読み上げ・ズーム)でステップを並べる操作部。映像の 1 クリップ = 1 ステップ | `timeline.tsx` |
| クリップ | タイムラインの映像トラック上の 1 ステップ | — |
| 吸着 | シークや枠の操作が切れ目・中心線などに寄ること | — |
| 設定パネル | 右端のパネル。左のサムネイル列で切り替える。全体の設定(全ステップ共通の値)か、ステップの詳細(録画・速度 / 文 / ズーム) | `step-rail.tsx`, `inspector.tsx` |
| 書き出し | mp4(と SRT)を作ること。UI と CLI の両方から | `exporter.ts`、`cli.ts` |
| 検証 | プロジェクトファイルが仕様どおりか調べること | `validate`、`src/core/validate.ts` |
| 移行(旧形式の変換) | 旧い書き方を読み込み時に今の形へ直すこと | `src/core/migrate.ts` |
| 外部変更の検知 | アプリの外でファイルが変わったら再読み込みすること | `src/main/project-files.ts` |
| M1 / M2 | 開発の段階。M1 = MVP(切り分け・テロップ・読み上げ・ズーム・書き出し)、M2 = ポインター・蛍光ペンなど | [decisions/20261029-mvp-scope.md](decisions/20261029-mvp-scope.md) |
