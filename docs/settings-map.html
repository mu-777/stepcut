設定の地図

プロジェクトファイルの設定が何に属していて、画面のどこから変えるのかを図にした資料です。データの正は src/core/schema.ts。図 1・3・4 は UI を整理する前(2026-11-07)の画面で、整理の材料として残しています。整理後の置き場所は decisions/20261108-step-drilldown-ui.md。

3 つの層

設定は 3 つの層に分かれます。下の図はすべてこの 3 色で描いています。

共通(プロジェクト)

出力・背景・余白、テロップなどの既定の見た目、声・音量・辞書。時刻を持たず、全ステップに効く。

構成(ステップ)

録画・In/Out・速度・録画の音。映像クリップ 1 つが 1 ステップで、要素の入れ物になる。

要素(時刻を持つもの)

テロップ・読み上げ・保持・ズーム。M2 からポインター・蛍光ペン・図形。どれも「時刻 + 位置 + 見た目」の形。

◇ 画面側の位置(ズームしても動かない) ◆ 映像側の位置(ズームに追従) ⏱ ステップ内の時刻 点線の枠 = M2 で入る予定 赤い点線 = JSON でしか変えられない ⚠n = 下の「気づいたこと」の番号

気づいたこと

⚠1プレビューで触った録画の枠が、全ステップに効く

録画の枠(余白)はプロジェクトの設定です。プレビューで触れる対象のうち、全体に効くのはこれだけです。今見ているステップだけを直しているように見えます。

⚠2テロップの位置の行き先が隠れている

同じドラッグが、右の欄でプロジェクトを開いていれば全ステップ共通に、それ以外ならそのステップだけに効きます。

⚠3右の欄に、選んでいないものも全部並ぶ

ズームを 1 つ選ぶと、ステップの全項目が並び、選んだ所に色が付くだけです。M2 の要素が加わるとさらに長くなります。

⚠4読み上げの声・速さは 1 つ目にしか書けない

データでは読み上げ 1 つごとに持てます。右の欄では一覧の後ろに 1 組だけあり、ステップ全体の設定に見えます。

⚠5作る入口の数がばらばら

図 4 のとおりです。

⚠6JSON でしか変えられない項目が散らばっている

テロップの行間・揃え、ステップごとのフォント・色、共通の録画の音、ステップの読み上げの音量、エンジン。AI が書く前提で意図して省いたものと、作りかけのものが区別されていません。

○時刻と座標の決まりは一貫している

時刻はすべてステップ内の時刻、位置は画面側(◇ テロップ・余白)と映像側(◆ ズーム・ポインター・蛍光ペン)の 2 種類だけです。UI を整理するときの土台にできます。
