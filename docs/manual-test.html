手動確認の手順書

使い方

上から順に、書いてある操作をして「→」の結果になるか見ます。結果どおりなら OK、違えば NG を押し、出てきた欄に何が起きたかを書きます。最後に「NG をコピー」で NG の一覧をまとめてコピーし、そのまま Claude に貼れば直す作業に入れます。

  • 記録はこのブラウザにだけ残ります(別の端末とは共有されません)。
  • 前の節で作ったステップ・ズーム・オブジェクトを後の節でも使います。節の順に進めてください。
  • OS の読み上げ・フォント・書き出しのエンコーダーなど、開発環境(自動テスト)では確かめられないものには 実機 を付けています。
