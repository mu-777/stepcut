# ズームの帯は「拡大したまま保つ区間」、動きは帯の外で倍率から自動(2026-10-31 決定)

ズーム(ZM-01〜08、U-05)の時刻の意味、動きの時間、範囲の指定方法、枠(キーフレーム)による移動、表示の縦横比についての決定。OpenScreen と Screen Studio の仕様に合わせた。

## 決定

- `start` 〜 `end` は拡大したまま保つ区間。拡大の動きは `start` の手前、縮小の動きは `end` の後ろで行う。ステップの外にはみ出す分は切り詰める
- 動きの秒数(ズームにかかる時間)は既定で倍率から決める: 0.6 + 0.55 × ln(倍率) 秒(1.8 倍で約 0.92 秒、2 倍で約 0.98 秒)。`transition` を書けば上書き、`0` なら動きなしで切り替える(UI は秒数の欄。空欄で自動、欄の薄い字で自動の値を示す)。速度ではなく時間で指定する(速度だと倍率によって所要時間が変わり、予測しにくい)
- 前のズームの終わりから次のズームの始まりまで 1.5 秒未満なら、いったん戻らずに次の範囲へ移る
- ズーム中は既定で映像を止める(`hold` の既定を `true` にした)
- 範囲は枠(`keys[].rect`)で決める。既定は枠どおりの範囲だけを映し、録画を描く領域を枠の縦横比にして余白の内側の中央に置く(動きの途中は、映す範囲の縦横比に合わせて領域も変える)。テロップの位置は変えない。`keepAspect: true` なら録画の縦横比を保ち、枠と縦横比が違うときは中心を保って上下か左右を広げる(プレビューでは実際に見える範囲を点線で示す)。倍率は枠の大きさから決まる(枠が複数なら最初の枠)
- プレビューの枠の操作は録画の枠と共通([20261031-margin-layout.md](20261031-margin-layout.md))。右カラムで倍率・枠の幅と高さ・中心を数値でも入力できる(倍率を変えると中心と縦横比を保って枠が変わる)
- 追加: Z キー(再生位置に、帯の長さ 2 秒)、ズームのレーンのドラッグ・ダブルクリック、プレビューの右クリック、コピー・貼り付け(録画の大きさが違えば枠を換算)
- タイムラインでズームをクリックすると、プレビューで枠の編集を始める。枠の外のクリック(ドラッグなし)か Esc で確定する(「完了」ボタンは置かない。枠の外のドラッグは描き直し)
- ズーム中の移動は枠(キーフレーム)で表す: `keys: [{ t, rect }]`。`t` はステップ内の出力時刻で区間の中に早い順に置く。枠が 1 つなら動かない。2 つ以上なら枠と枠の間を一定の速さで移る(動き出しと止まりを滑らかにしない。流れる文字を追う用途で、速さが一定のほうが追いやすい)。最初の枠より前は最初の枠、最後の枠より後は最後の枠のまま。区間ごと動かすと枠の時刻も同じだけずれ、区間の長さを変えると端にあった枠は新しい端へ、間の枠は区間の中に収める
- 枠の UI: タイムラインのズームの帯に枠を ◆ で出す(クリックでその枠を編集、ドラッグで時刻、右クリックで削除)。編集中はプレビュー上部の帯に「◀ 枠 i/n ▶」「再生位置に枠を追加」(その時刻に見えている範囲で作るので映像は飛ばない)「サイズを全枠でそろえる」を出す。プレビューでは編集中でない枠を点線で出し、中心どうしを線でつなぐ。点線の枠のクリックでその枠の編集に切り替える。右カラムに枠の一覧(時刻・編集・削除)
- 「サイズを全枠でそろえる」(既定オン): 1 つの枠の大きさを変えると、ほかの枠も同じ大きさにする(それぞれの中心は保つ)。編集の操作の設定なので、ファイルには保存せず端末に覚える
- 「録画の縦横比に戻す」ボタン: 倍率と中心を保ったまま、全部の枠を表示の縦横比にする

## 理由

- 調査(2026-10-31): OpenScreen はズームの帯を拡大したまま保つ区間とし、拡大の動きを帯の手前、縮小を後ろに置く(`src/lib/ai-edition/timeline/zoom-transitions.ts`)。動きの時間はズームごとの設定ではなく倍率から決める(`src/lib/zoomMath/constants.ts`: 600 + 550 × ln(倍率) ms)。間が 1.5 秒未満なら横移動する。Z キーで再生位置に追加する(`src/lib/shortcuts.ts`)。Screen Studio はズームごとに「Instant Animation」(動きなし)を選べる(公式ガイド Instant Zoom)
- 帯の内側で動くと「帯の長さ = 拡大して見える長さ」にならず、旧 UI の「切り替え(秒)」が分かりにくかった
- 手順書では拡大した場面を読ませたいので、映像を止める方が既定に合う(ユーザー判断)

## 不採用案と理由(逆戻りガード)

- **帯の内側で拡大・縮小する(旧仕様)** — 帯の長さと拡大して見える長さが一致しない
- **ズームごとに動きの秒数を必ず設定する(旧 UI の「切り替え(秒)」、既定 0.4 秒)** — 意味が伝わらず、速すぎた。既定は倍率から自動にし、上書きだけを許す
- **移動を開始枠と終了枠(`rect` と `to`)だけで表す(11/05 までの仕様)** — 途中で向きを変える動き(文字を追って折り返すなど)を表せない。枠(キーフレーム)の並びにまとめた
- **開始枠・終了枠を残して中間の枠だけ足す(`via`)** — 枠の置き場所が 3 か所に分かれる。リリース前なので互換性より形のそろいを優先した(ユーザー判断)
- **枠の時刻をズームの区間に対する割合で持つ** — 映像を流すズームで、映像の中身に合わせた時刻にならない
- **「サイズをそろえる」をズームごとにファイルへ保存する** — 書き出しの見た目に関係しない編集の操作なので、保存しない
- **ズームが続くときの移動(1.5 秒未満で横移動)だけで移動を表す** — 動きが加減速するので、一定の速さで文字を追えない
- **倍率の段階ボタン(OpenScreen の 6 段階)と中心の点で指定する** — ユーザーの指定で、範囲の枠で決める方式にした
- **範囲を表示の縦横比に強制する(旧仕様)** — 四辺のハンドルで縦横比を変えられない
- **録画の縦横比を保つ(枠を広げる)を既定にする(11/05 までの既定)** — 指定した枠と見える範囲がずれる。ユーザーの指定で枠どおりを既定にした

## 前提と再検討の条件

- 既存のプロジェクトで `hold` を書いていないズームは映像を止めるようになる(M1 段階なので許容)
- `start` の手前に動きの時間がないズーム(ステップの先頭付近)は、ステップの始まりで拡大した状態から始まる
