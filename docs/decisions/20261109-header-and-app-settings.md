# メニューバーを隠し、操作はヘッダーに集め、アプリの設定を足す(2026-11-09 決定)

編集画面のいちばん上(メニューバーとヘッダー)の決定。何を置き、プロジェクト名をどう見せ、プロジェクトによらない設定(アプリの設定)をどこに持つか。設定パネル・サムネイル列の置き場所は [20261108-step-drilldown-ui.md](20261108-step-drilldown-ui.md)。

## 決定

- **メニューバー**: Windows では出さない(`setMenuBarVisibility(false)`)。メニュー自体は残し、Ctrl+N/O/S/Shift+S/E/Z/Shift+Z/`/` のキーと、コピー・貼り付け(role)、開発者ツール・再読み込み(View の role)に使う。Mac はメニューが画面上端の別の場所にあるのでそのまま
- **ヘッダー**: 高さ約 52px。ボタンはアイコンの下に短い文字(「…」は付けない)。左から
  - ファイル: 新規・開く・保存・名前を付けて保存(メニューにしかなかったものをここへ)
  - 録画を追加
  - 元に戻す・やり直し
  - 真ん中: プロジェクトの名前(ファイル名から `.sanno.json` を除く)と、未保存なら ●。その下に小さくフォルダー(未保存なら「まだ保存していません」)。全体のパスはツールチップ
  - 右端: 設定(アプリの設定)、書き出し(強調色)
- ウィンドウのタイトル(タスクバー)は「● 名前 — Screen Annotator」
- **アプリの設定**: ヘッダーの「設定」でダイアログを開く。変えたらすぐ保存する
  - 言語(OS に合わせる / 日本語 / English)。切り替えると開いている画面の文言がその場で変わる
  - プロジェクトの保存先: 新しいプロジェクトを保存するときと、開くときに最初に出すフォルダー
  - 保存先はユーザーデータのフォルダーの `settings.json`(メインプロセスが持つ)

## 理由

- メニューバーの項目はほぼヘッダーと重複していた。重複をなくし、画面の縦を空ける(ユーザーの指摘)
- メニューを丸ごと消すとキー操作(accelerator)とコピー・貼り付けの役割が効かなくなるため、隠すだけにする
- 書き出しは最後にする操作なので右端に離し、ほかの操作と取り違えないよう色を変える
- プロジェクト名は、真ん中に名前だけを大きく出すと、どのファイルを直しているかと未保存かが一目で分かる。パスは長いので小さく下に
- 保存先は開く・保存のダイアログ(メインプロセス)が使うので、レンダラーの localStorage ではなくメインのファイルに置く

## 不採用案と理由(逆戻りガード)

- **メニューを消す(`Menu.setApplicationMenu(null)` / `removeMenu()`)** — Ctrl+S などのキーとコピー・貼り付けが効かなくなる
- **Alt で出す自動で隠れるメニューバー(`autoHideMenuBar`)** — Alt を押すと急に出てきて画面がずれる。ヘッダーに全部あるので出す理由がない
- **プロジェクト名をヘッダーの右端に小さく出す(前の形)** — 書き出しを右端に置くと押し出され、長いパスで書き出しが見切れる
- **プロジェクト名をウィンドウのタイトルだけに出す** — Windows のタイトルバーは目に入りにくく、未保存の印が見落とされる
- **アプリの設定をレンダラーの localStorage に置く** — 保存・開くのダイアログ(メイン)から読めない。設定ファイルとして人が直すこともできない

## 前提と再検討の条件

- メニューにしかない操作を足すときは、ヘッダーかキー操作の一覧に置き場所を作る(メニューバーは見えないため)
- アプリの設定の候補(未実装): 書き出しの保存先の既定、VOICEVOX 互換エンジンの場所と自動起動、ハードウェアエンコーダーを使うか、パネルの幅などの表示を初期状態に戻す。足すときはこの記録を書き換える
