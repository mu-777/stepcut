# 座標系は要素の種類ごとに固定(2026-10-26 決定)

ポインター・蛍光ペン・図形・テロップ・ズーム範囲の座標を、ソース映像基準と出力画面基準のどちらで持つかについての決定。

## 決定

| 要素 | 座標系 |
|---|---|
| ポインター(蛍光ペンを含む)、ズーム範囲 | 映像側(ズームに追従) |
| 図形(四角・矢印・文字。四角には画像を入れられる) | 図形ごとに選ぶ。既定は映像側、「画面に固定」で画面側([20261109-objects.md](20261109-objects.md)) |
| テロップ(枠付き) | 帯の中 |
| テロップ(全画面) | 画面側(固定) |

図形以外は、要素ごとにユーザーが座標系を選ぶ方式にはしない。

## 理由

指し示す対象が映像内のものは映像側、文字は画面側で固定すれば足りる。選択式にすると実装と操作が複雑になる。図形だけは、背景に見出しを置く・録画の外から録画の中を指すといった使い方が録画の領域の中だけでは作れないため、選べるようにした(ユーザーの指示)。

## 不採用案と理由(逆戻りガード)

- **すべての要素で座標系を選べるようにする** — 実装と操作が複雑になる。ポインター・蛍光ペンは録画の中を指すものなので映像側だけで足りる
- **図形を画面側だけにする** — 録画の中のボタンを囲む四角が、ズームすると対象からずれる

## 前提と再検討の条件

ポインター・蛍光ペンを録画の外にも置きたい要望が出たら、図形と同じ選び方を足すかを検討する。
