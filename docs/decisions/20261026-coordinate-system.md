# 座標系は要素の種類ごとに固定(2026-10-26 決定)

ポインター・蛍光ペン・テロップ・ズーム範囲の座標を、ソース映像基準と出力画面基準のどちらで持つかについての決定。

## 決定

| 要素 | 座標系 |
|---|---|
| ポインター、蛍光ペン、ズーム範囲 | 映像側(ズームに追従) |
| テロップ(帯あり) | 帯の中 |
| テロップ(余白なし) | 画面側(固定) |

要素ごとにユーザーが座標系を選ぶ方式にはしない。

## 理由

指し示す対象が映像内のものは映像側、文字は画面側で固定すれば足りる。選択式にすると実装と操作が複雑になる。

## 不採用案と理由(逆戻りガード)

- **要素ごとに座標系を選べるようにする** — 実装と操作が複雑になる
- **図形(四角・矢印・吹き出し等)を入れる** — 映像側・画面側のどちらにも置きたくなり座標系が複雑。当面はポインターで足りる見込みのため将来の候補に回した

## 前提と再検討の条件

図形を追加する段階(要件 3.3)で、図形の座標系を改めて決める。
