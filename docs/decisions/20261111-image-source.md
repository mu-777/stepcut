# 画像は録画と同じ「素材」として足し、ステップの長さを in / out で持つ(2026-11-11 決定)

タイムラインの映像の段に、録画(mp4)だけでなく画像(表紙・補足のスクリーンショットなど)を置けるようにするときの、プロジェクトファイルでの持ち方と編集のしかた。

## 決定

- 画像は `sources` に録画と同じ形(`id` と `path`)で入れる。種類は `path` の拡張子(png・jpg・jpeg・webp)で決め、キーは足さない
- 画像はどの時刻でも同じ 1 枚・音なしの素材として扱う(読み込みでは無限の長さの素材)。ステップの `in` / `out` は長さだけを表し、足したときは `in: 0`、`out: 3`
- 編集: クリップの右端・左端のどちらでも伸び縮みできる(左端は `in` を 0 のまま `out` を変え、後ろの要素をずらす)。設定パネルは In/Out・速度・録画の音声の代わりに「長さ」を出し、クリップの右クリックに録画の音の項目を出さない
- 画像を使うステップでも、テロップ・読み上げ・ズーム・オブジェクト・フェード・保持はそのまま使える(座標は画像のピクセル)

## 理由

- ステップ・タイムライン・合成・書き出しは「素材の時刻 → フレーム」だけに依存しているので、画像を「どの時刻も同じフレームを返す素材」にすれば、ほかは変えずに済む(C7)
- 拡張子で決めると、AI や人がファイルを書くときに覚えることが増えない。画像を録画として読もうとして失敗することもない

## 不採用案と理由(逆戻りガード)

- **ステップに `duration` などの専用のキーを足す** — 長さの持ち方が 2 通りになり、分割・結合・トリムをすべて書き分けることになる
- **`sources` に `kind: "image"` を足す** — 拡張子と食い違う書き方ができてしまう。拡張子で決まるので不要
- **画像を図形(四角の画像)として録画の上に置く** — 録画のないステップを作れない。表紙のように画像だけの場面を作るのが目的
- **左端のドラッグで `in` を負にする** — 時刻は 0 以上の決まり(schema)を崩すことになる。画像は時刻に意味がないので `in` を 0 にそろえる

## 前提と再検討の条件

- 画像のアニメーション(GIF・APNG)は扱わない(最初のフレームだけ)。動く素材が要るなら mp4 にする
- 素材の種類が増えて拡張子で決められなくなったら(拡張子のない素材など)、`kind` を足すことを見直す
