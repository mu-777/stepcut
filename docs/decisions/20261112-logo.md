# ロゴは「画面とテロップ + カチンコの棒」、青 1 色・地なし(2026-11-12 決定)

アプリのアイコン、LP、favicon で使うロゴの形・色・使い分けの決定。元データは `assets/logo/`。

## 決定

- マーク: 角丸の画面の枠の中に、切れ目の入ったテロップの帯。その上に、縞 3 本のカチンコの棒(閉じた形)。64 のマス目で、棒の高さ 7.5、画面の線の太さ 5、棒と画面のすき間 2.5
- 色: アプリの `--accent` と同じ `#4f8cff` の 1 色。明るい地でも色は変えない
- 地: 付けない(アプリのアイコンも地なし)。地が要る場面(OGP 画像、将来の macOS 版など)では、マークの大きさを変えずに白地を敷く(`stepcut-mark-on-white.svg`)
- 文字: 「StepCut」を Sora の太字(700)、単色(暗い地では白、明るい地では `#1e1f22`)。SVG ではアウトラインにし、フォントのファイルは置かない
- Windows のアイコン: `assets/logo/stepcut-icon.svg`(余白を詰めた版)から `node scripts/make-icon.cjs` で `build/icon.ico`(16〜256px)を作り、コミットする

## 理由

- テロップを軸に作る、というこのアプリの特徴を形にする。画面とテロップだけでは字幕(CC)のアイコンに見えるので、カチンコの棒で動画のアプリだと分かるようにした
- Windows 11 のアイコンは、地の板に載せずモチーフの輪郭を見せるのが指針([Microsoft のガイドライン](https://learn.microsoft.com/en-us/windows/apps/design/style/iconography/app-icon-design))
- 青のコントラスト比(WCAG): 白 3.22、明るいタスクバー相当 `#f3f3f3` 2.90、暗いタスクバー相当 `#202020` 5.06、アプリの地 `#1e1f22` 5.12。目安の 3 を下回るのは明るいタスクバーだけ。暗い地で使うのが主なので、色をそろえることを優先した
- Sora は SIL OFL 1.1。アウトラインにした図形は同梱できる(C3)

## 不採用案と理由(逆戻りガード)

- **階段の形で切った四角 / 再生の三角を 3 本の帯で / タイムラインと再生ヘッド / 階段の S** — ユーザーがカチンコ風を選んだ。3 本の帯は Descript のロゴ(長さの違う線を重ねた形)と発想が近い
- **カチンコだけ(閉じた形・開いた形)** — 多くの動画アプリ・OS の標準アイコンにあり、見分けがつかない
- **棒を太く(高さ 11)/ さらに細く(6)** — 太いと棒が画面より重く見える。6 では 24px 以下で縞が点線になる
- **青い地 + 白のマーク / 暗い地 + 青** — 16px での見やすさのために検討したが、ユーザーが地なしで足りると判断。Windows では地なしが本流
- **アイコンだけ濃い青 `#3f7df5`**(明るいタスクバーで 3.46) — 色が 2 種類になる。差は 0.1 なので統一を優先
- **文字の「Cut」だけ青 / 小文字 + オレンジの切れ目** — ユーザーが単色の太字を選んだ

## 前提と再検討の条件

- 商標・既存のロゴとの類似は調べていない。公開の範囲を広げる前に確認する
- macOS へ移植するときは、macOS の流儀(角丸の四角の地)に合わせた版を足す
- 明るいテーマの画面を作る、または明るい地で使う場面が主になったら、青の濃さを見直す
