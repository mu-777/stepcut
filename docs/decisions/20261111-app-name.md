# アプリの名前は StepCut(2026-11-11 決定)

仮の名前(Screen Annotator)に代わる、アプリの名前と副題の決定。表示名・CLI のコマンド名・appId・プロジェクトファイルの `format`・CI の Artifact 名に効く。GitHub のリポジトリ名は対象外(別途変える)。

## 決定

- 名前: **StepCut**(コマンド名・パッケージ名は `stepcut`、appId は `com.mu777.stepcut`、プロジェクトファイルの `format` は `stepcut.project`、拡張子は `.stepcut.json`)
- 副題: **Turn recordings into step-by-step videos, driven by captions.**
- 旧名のプロジェクトファイルは読めない(読み替えの処理は置かない)

## 理由

- このツールが他の動画編集ソフトと違うのは、時間(タイムライン)ではなく「ステップ + 1 文」の列を編集させる点。ステップが最上位の単位で、テロップの文から読み上げとステップの長さが決まる(`stepDuration`)。名前はこの単位(step)と動画編集(cut)の 2 語にした
- step・cut はどちらも日本語として通じる(ステップ、カット)
- 副題は用途を絞らない。チュートリアル以外(デモ、機能紹介、不具合の再現)にも使えるので tutorials と書かない。素材は画面録画に限らないので screen recordings ではなく recordings
- 副題の「driven by captions」: caption-first(書く順序)ではなく caption-driven(テロップが読み上げと長さを決める)のほうが仕組みに合う
- 開発中で配布前なので、旧名との互換よりコードの簡潔さを優先した

## 不採用案と理由(逆戻りガード)

- **StepShot** — 同名の手順書作成ツールがあった(2019 年に UiPath が買収)。同じ分野で、shot は静止画を連想させる
- **StepsCut** — 「steps cut(手順が削られた)」と読める。発音・入力もしにくい。複数形の Steps は歩数計アプリの語
- **StepVideo / StepMovie / StepClip / StepReel / Stepcast** — StepVideo は同種のサービスが実在。ほかは動画編集の印象が cut より弱い
- **Cut by Step** — 同名は見つからず検索で独立しやすいが、3 語で、略すと CBS。次点
- **RecipeCut** — 「書いたものが原本」を表す案。何のツールか伝わらなかった
- **ScriptCut / TextCut / CaptionCut / TelopCut** — 「文字起こしを消して映像を切る」「動画に字幕を付ける」種類のツールと読まれ、向きが逆。ScriptCut・AI Caption Cut は実在。Telop は英語として通じない
- **Cut the Steps** — 英語で「手順を省く」の意味になる

## 前提と再検討の条件

- 同名の確認は一般の Web 検索のみ。KNIPEX のケーブルカッター「StepCut」(手工具。別分野)と、GitHub のユーザー名 `stepcut`(別分野の個人)がある。ソフトウェアの同名製品は見つかっていない
