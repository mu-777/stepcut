# オブジェクト(ポインター・図形)の持ち方と編集のしかた(2026-11-09 決定)

録画の上に重ねる強調(ポインター・四角・矢印・文字)を、プロジェクトファイルでどう持ち、どう描き、画面でどう作って直すかの決定。蛍光ペンはポインターの見た目の 1 つ、画像は四角の中身として持つ。座標系は [20261026-coordinate-system.md](20261026-coordinate-system.md)、設定パネルの置き場所は [20261108-step-drilldown-ui.md](20261108-step-drilldown-ui.md)。

## 決定

- **持ち方**: ポインター `pointers[]` は M1 で決めた形(時刻付きの点の列 `path`)のまま。図形は 1 つの配列 `shapes[]` に `type`(`rect` / `arrow` / `text`)で入れる。配列の順が重なりの順(後ろほど手前)
  - 蛍光ペンは、見た目(`style.preset`)が `"highlighter"` のポインター。動きに沿って線を引く。色・線の太さ(映像側の px)・不透明度を `style.color` / `width` / `opacity` に持つ。M1 の `highlights[]` と `styles.highlighter` は、読み込むときに蛍光ペンのポインターへ直す
  - ポインターの見た目は 矢印のカーソル・丸・輪・蛍光ペン・ユーザーの画像。丸・輪にも色を付けられる
  - 画像は四角の `image`(ファイルのパス)。塗り → 画像 → 線の順に描くので、線を付ければ画像の枠になり、透明な所には塗りが見える
  - 出ている間は、ポインターが `path` の最初の点〜`end`、図形が `start`〜`end`。`end` を省略するとステップの終わりまで。`end` が映像より後なら、読み上げと同じく最終フレームを保持してステップを伸ばす。タイムラインで終わりを引くとステップの終わりで一度止まり(24px の幅。そこで離すと `end` 省略)、さらに引くと伸ばす(意図せず伸ばさないため)
  - 四角・文字は枠 `rect`、矢印は `from` / `to` で持つ。ポインターの座標は映像側(ソースのピクセル)
  - 図形は図形ごとに座標の基準 `anchor` を選ぶ。省略(既定)は映像側。`"screen"` は画面側で、出力の高さ 1080 を基準にした px(テロップの文字の大きさと同じ考え方)。太さ・角の丸み・文字の大きさも同じ単位になる
  - 見た目は `styles.pointer` / `rect` / `arrow` / `text`(全体)を要素の `style` で上書きする(STY-01, 02)
  - 現れ方・消え方 `enter` / `exit` は種類だけ(`"fade"` / `"flash"`)か、長さ・点滅の回数も書く形(`{ "type": "flash", "duration": 1, "count": 5 }`)。既定は fade 0.3 秒、flash 0.6 秒に 3 回。長さは出ている間を上限にし(現れ方と消え方の長さの合計が出ている間を超えてもよい。重なる時刻は暗い方)、点滅は長さの中で均等に繰り返す。長さを出ている間と同じにすれば、出ている間ずっと点滅する
  - 画像ファイル(四角の画像・ポインターの画像)は素材と同じ規則で、保存するときにプロジェクトからの相対パスにする
- **描画**: 録画 → 蛍光ペンのポインター → 図形 → ほかのポインター → テロップの順。映像側のものは録画の領域で切り、ズームの変換をかけて描く(ズームに追従する)。画面に固定した図形はズームの影響を受けず、画面全体(背景・録画にまたがる位置)に描く。ポインターの大きさだけは出力の px で持ち、ズームしても大きくならない
  - ポインターは直線ではゆっくり動き出して止まり、フリーハンドは一定の速さ。最後の点に着いたらクリックの波紋を出せる(`click`)
  - 蛍光ペンは点の時刻に合わせて線を引いていき、引いた線は `end` まで残る
- **作る**: プレビューの下の追加の段(アイコンと名前のボタン)・プレビューの右クリック・タイムラインのオブジェクトの段の右クリック・設定パネルのオブジェクトの欄から、ポインター・蛍光ペン・四角・矢印・テキスト・画像を再生位置(タイムラインの右クリックならその時刻)に作る。いま見えている範囲(ズーム中ならその範囲)の中央付近(プレビューの右クリックならクリックした点)に置き、3 秒出す。録画の外で右クリックして作った図形は画面に固定する(ポインター・蛍光ペンは録画の中央)。文字はすぐ文を打てるようにする(プレビュー上の入力欄で、仮の文を選んでおく)
  - 蛍光ペンと画像は近道で、データの種類は増やさない。「蛍光ペン」は見た目を蛍光ペンにしたポインターを作る(全体の設定のポインターの見た目が蛍光ペンなら見た目を書かない。逆にそのとき「ポインター」は見た目を矢印にして作る)。「画像」は先にファイルを選ばせ、画像を入れた四角を画像の縦横比で(見えている範囲の幅 1/4・高さ 1/2 に収めて)作る。取り消したら何も作らない
  - 作った後に見た目を蛍光ペンにする・四角に「画像を入れる…」で画像を入れる(入れたときに四角を画像の縦横比に合わせる)こともできる
- **直す**: プレビューでクリックして選ぶ(手前のものから当たりを調べる)。四角・文字は録画・ズームと同じ枠の取っ手(`BoxEditor`。中心固定・隅固定の切り替えも同じ)、ポインター・矢印は両端の取っ手と線のドラッグ。ポインターは水平、矢印は 45 度ごとに吸着(Alt で吸着しない)。ズーム中も、見えている位置のまま直せる
  - 文字の文はテロップと同じく、プレビュー上で枠をクリック(ドラッグなし)するとその場で入力する(2026-11-19、ユーザー判断)。選んでいない文字でも 1 回のクリックで入力を始める。入力欄は描画と同じ書体・大きさで重ね、キャンバスの文は描かない(枠の塗りは描く)。ドラッグなら移動、取っ手なら大きさの変更
  - タイムラインは「オブジェクト」の段を 1 つ足し、重なる時刻のものは行を分けて積む。帯の移動・両端で出ている間を変える。ポインターは動き・線を引く区間を帯の中に薄く示し、始まりを動かすと動きごとずらす
  - 設定パネルはステップの詳細に「オブジェクト」の欄を足し、始まりの時刻の順に並べる(同じ名前には番号、画面に固定した図形には印)。項目はいくつでも開いたままにでき、選んだものを強調する。タイムライン・プレビューで選ぶとそれだけを開いてほかを閉じ、設定パネルで開いたものは開いた項目に足す(見比べたいときだけ足していける)。中身(テキストの文・四角の画像)を一番上に、続けて小見出し「見た目」「時間」「位置」に分ける。位置(座標の基準と数値)はプレビューの取っ手で直すことが多いので畳んでおく。複製・前面へ・背面へ・削除は開いた項目の見出しの右にアイコンで並べる。色は小さな見本と色の値、単位はラベルではなくマウスを重ねたときの説明に出す。蛍光ペン・画像・文字の見出しは「ポインター(蛍光ペン)」「四角(画像)」「テキスト(文の 1 行目)」(種類が分からないため)。全体の設定に「オブジェクトの見た目(共通)」の欄
  - 少ない選択肢(ポインターの見た目・現れ方・消え方・位置の基準)は選択欄ではなく横に並べたボタンにする(何があるか一目で分かる)。ポインターの見た目はアイコンのボタンを 1 列に並べ、その下の 1 列を選んだ見た目の設定(色・大きさ・太さ・不透明度・画像)に変える。現れ方・消え方は 1 行ずつ使い、フェードは長さ、点滅は長さと回数を並べる
  - 図形の「位置の基準」で「録画に追従」と「画面に固定」を切り替える。切り替えたときは再生位置で見えている位置と大きさを保つよう座標と書いてある太さ・文字の大きさを換算する(ズーム中に切り替えればズームした見た目のまま固定される)。画面に固定した図形は、画面の辺に加えて録画の辺にも吸着する
  - 録画に追従する図形が録画の外にはみ出していたら(はみ出た所は描かれない)、設定パネルの項目の見出し・位置の小見出し・オブジェクトの欄の見出し(畳んでいても見える所)に ⚠ を、タイムラインの帯を赤い縞にして「⚠ 録画外にはみ出し」を出す
  - 四角の線・塗りはチェックで出す・消す(消すと太さ・不透明度を 0 にする)。テキストの背景の塗りもチェックで出す・消す
  - 録画の外にはみ出した図形をプレビューで選ぶと、選択の枠を赤にする
  - 新しいポインターは、左から水平に動いてきてクリックした点に着く(斜めより、手順書でよくある横の動きに合わせる)
  - 停止中は、選んでいるオブジェクトを、出ている間ならフェード・点滅で見えない時刻でも不透明に出す(直す対象が見えるように)。再生中と書き出しは効果どおり
  - 削除は Delete、複製・前面へ・背面へは右クリック(タイムライン・プレビュー)と設定パネル。Ctrl+C / Ctrl+V でコピーし、再生位置を始まりにして貼る(録画の大きさが違えば座標を換算)
  - ステップを分割したとき、分割点をまたいで出ているオブジェクトは前半のステップの終わりまで出す(後半には移さない)

## 理由

- 図形は種類ごとに配列を分けると、四角と矢印の重なりの順を表せない。1 つの配列に `type` で入れれば、配列の順がそのまま重なりの順になり、AI も「後ろに足せば手前」と書ける
- ポインターは M1 の時点で形を決めて公開済み(C5)なので、図形の配列に混ぜず別の配列のまま置く
- 蛍光ペンとポインターはどちらも「時刻付きの点の列をたどる」もので、違いは見た目だけ。種類を分けると追加の選択肢・設定の欄・吸着の規則が二重になる(ユーザーの指摘でまとめた)。M1 の `highlights[]` は描画されない段階で公開していたので、読み込み時に直せば失うものがない
- 画像を独立した図形にすると、枠を付ける・角を丸める・下地の色を敷くたびに四角を重ねることになる。四角の中身にすれば線・塗り・角の丸みをそのまま使える(ユーザーの指摘)
- 手順書の強調は、録画の中のボタンや欄を囲む・指すものが大半で、ズームしても対象からずれてはいけない。そのため既定は映像側にした
- 一方で、背景に見出しを置く・録画の外から録画の中を指す矢印・録画の端にまたがる枠は、録画の領域で切ると作れない(ユーザーの指摘)。映像側のまま切らずに描くと、ズームしたときに見えない部分のものが背景へ大きくずれて出るため、図形ごとに画面側を選べるようにした。映像側のまま録画の外へ出した図形は欠けて描かれるので、気付けるよう印を出す
- 作る・選ぶ・動かすはプレビュー、細かい数値は設定パネルという流れ(PowerPoint・Keynote 型)を、テロップ・ズームと同じにそろえる
- 蛍光ペン・画像は手順書でよく使うのに、ポインター・四角を作ってから設定パネルで切り替えないと作れず、見つけにくかった(ユーザーの指摘)。データの種類は分けずに、作る操作の選択肢にだけ近道として足した。追加の選択肢は 2 つ増えるが、設定の欄・吸着の規則は二重にならない
- タイムラインの段を種類ごとに足すと縦に伸びすぎる。1 段にまとめ、重なるときだけ行を増やす

## 不採用案と理由(逆戻りガード)

- **図形を種類ごとの配列(`rects[]` / `arrows[]` …)に分ける** — 種類をまたいだ重なりの順を持てない
- **ポインターも `shapes[]` に入れる** — M1 で公開した形が変わる(C5)
- **蛍光ペンを `highlights[]` として別の種類のまま持つ** — 見た目以外はポインターと同じで、設定・吸着が二重になる(作る操作の選択肢には近道として出す)
- **画像を `shapes[]` の `type: "image"` として持つ** — 枠・角の丸み・下地を付けるのに四角を重ねることになる
- **図形を画面側の座標だけで持つ** — 録画の中を囲む・指す図形が、ズームすると対象からずれる
- **図形を映像側だけで持つ(録画の領域で切る)** — 背景への配置・録画と背景にまたがる配置ができない(ユーザーの指摘で選べるようにした)
- **映像側のまま、録画の領域で切らずに描く** — ズームすると、見えていない範囲のものが拡大された位置で背景に出てしまう
- **画面側の座標を出力に対する割合(0〜1、テロップの位置と同じ)で持つ** — 四角の幅と高さが出力の縦横比で伸び縮みする。太さ・文字の大きさも同じ単位で書ける 1080 基準の px にした
- **文字の大きさを出力の px(テロップと同じ)で持つ** — ズームすると囲んだ四角や指した対象との大きさの関係が崩れる。映像側の px にして一緒に大きくする
- **ポインターの大きさを映像側の px で持つ** — ズームで矢印のカーソルが大きくなりすぎる。本物のカーソルと同じく画面上の大きさを保つ
- **オブジェクトを選ぶとズームを外して表示する(ズーム範囲の編集と同じ)** — ズーム中に小さなボタンへ印を付けたい場面が多い。描画と同じ変換で、見えている位置のまま直せるようにした
- **タイムラインに種類ごとの段を足す** — 段が増えて縦に伸びる
- **設定パネルで開ける項目を 1 つにする(選んだものだけ開く)** — 2 つのオブジェクトの設定を見比べながら直せない(ユーザーの指摘)

## 前提と再検討の条件

- 円・吹き出しなどほかの図形は要件 3.3(将来の候補)。足すときは `shapes[]` に `type` を増やす
- フリーハンドの記録(ANN-04)は M3。データの形と描画はすでにフリーハンド(点が 3 つ以上)に対応している
- プレビュー上での文字の直接入力はまだない。要望があれば足す
