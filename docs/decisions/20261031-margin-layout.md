# レイアウトは上下左右の余白で持ち、録画の枠はプレビューで操作する(2026-10-31 決定)

レイアウトモード(帯あり/全画面)、帯の高さ、録画の位置と大きさ(LAY-01〜08)、テロップの置き方(TXT-02・03、U-03)についての決定。「画面を小さくして背景を見せる」ことをどう表すか。

## 決定

- モードをやめ、`layout.margin: { top, right, bottom, left }` で録画の周りの余白を持つ。上下は出力の高さ、左右は出力の幅に対する割合。すべて 0 なら全画面
- 録画は余白の内側に縦横比を保って収める(`fit: "contain"`、既定)。`fit: "cover"` なら余白の内側いっぱいに描き、はみ出す録画の端を切り取る
- 既定の余白は上 4%・下 20%・左右 2.25%(16:9 の出力で上と同じ幅)。旧「帯あり」の既定と同じ見た目
- 旧い書き方(`mode` / `bandHeight` / 数値の `margin` / `video`)は読み込み時に `margin` へ直す
- 余白・置き方・影(録画の枠)は全体の `layout` を持ち、ステップの `layout` で書いた項目だけ上書きする(背景は全体だけ)。テロップの位置と同じ継承。プレビューでの枠の操作は再生位置のステップの上書きを変え、全ステップにそろえるのはステップの詳細の「この枠を共通にする」(全体の枠にし、そのステップの上書きを消す。ほかのステップの上書きは残す)。「全体の枠に戻す」で上書きを消す。全体の設定パネルの枠の欄は、上書きのないステップに効く
- 枠が変わったステップでは、位置を書いたテロップを枠に合わせて動かす。全体の位置を使っているステップは、全体の位置の動きと自分の枠の動きが食い違うとき、自分の位置として書く
- プレビューの枠の操作(ズームの範囲と共通): 枠の中のドラッグで移動、四隅のハンドルで縦横比を保ったまま拡大縮小、四辺の中央のハンドルで縦横比を変える。拡大縮小の基準は「中心固定」(既定)と「隅固定」(反対側の角・辺を固定)をプレビューの真下の帯で切り替える(設定は端末に覚える)。録画の枠では、縦横比を変えると `fit: "cover"` になる。移動・拡大縮小とも、出力の縦横の中心線と画面の上下左右の辺に吸着する(12px 以内、Alt で解除。ズームの枠は録画の中心線と辺)。選択中は矢印キーで 10px(Shift で 1px)ずつ動かす(録画は出力のピクセル、ズームは録画のピクセル。ユーザー指定。一般的な図形編集ソフトは逆だが、シークの Shift+←→ が 1 フレームなので「Shift = 細かく」でアプリ内をそろえた)。ドラッグでの移動は枠の大きさを変えず、ズームの枠は録画の内側だけを動く(端で切り詰めて縮めない)。余白は小数 6 桁で持つ(1px の移動が丸めで消えないように)
- 「余白なし」: オンで余白を 0・`contain` にする。オフでオンにする前の余白と置き方に戻す(アプリを閉じるまで覚える。保存はしない)
- 録画がないときも録画を置く場所は黒で示し、その中央に「録画・画像を追加…」のボタンを出す。押すとファイルの選択を開く(確認は挟まない)。押せるのはボタンだけで、黒い所の他のクリックでは開かない(狙わないクリックで開かないように)。以前はダブルクリック(確認のうえ)だったが、見えない操作で気付きにくいのでやめた(ユーザー指定)
- 全体の設定では余白を出力のピクセルで入力する(保存は割合)
- テロップは余白によらず表示する。位置(中心)と折り返し幅は継承: ステップの `caption.position` / `width` → `styles.caption.position` / `width` → 既定。既定の位置は、録画の下の余白に収まるならその中央、収まらなければ画面の高さ 88%。文字の背景の箱は既定で付けない。プロジェクトとステップごとに「なし／あり」を選ぶ(旧い `"auto"` は箱なし)
- プレビュー上でテロップをドラッグできる。ドラッグは常にそのステップの個別設定を変え、全ステップ共通にするのはステップの詳細の「この位置を共通にする」([20261108-step-drilldown-ui.md](20261108-step-drilldown-ui.md))。左右の中央、録画の下の余白の中央、録画の下辺(テロップの上辺)、画面の下辺(テロップの下辺)に吸着する。クリック(ドラッグなし)でそのステップのテロップの設定へ移る

## 理由

- OpenScreen・Screen Studio とも、画面を小さくする設定はモードではなく余白(Padding)の量で持つ(OpenScreen: `src/i18n/locales/en/settings.json` の "Padding"、日本語表示「余白」。Screen Studio: 公式ガイド Background の "Padding: At zero, no background shows")。ユーザーは上下左右を別々に決めたい
- テロップの帯は余白の一部として扱える。モードごとにテロップの置き方を分ける必要がなくなる
- 中心固定の拡大縮小は、ズームの範囲と録画の枠で操作を統一でき、位置がずれにくい
- テロップ位置と録画の枠の継承は、全ステップを一度にそろえつつ、例外のステップだけ変えられる(スライドマスターと同じ考え方)。表紙の画像だけ全画面にする、などの例外がある
- プレビューのドラッグをステップの上書きにするのは、テロップのドラッグと同じ規則にそろえるため(ユーザー指定)

## 不採用案と理由(逆戻りガード)

- **プロジェクトの設定を開いているときのテロップのドラッグで、共通の位置を変える(11/08 まで)** — 行き先が画面から読めない([20261108-step-drilldown-ui.md](20261108-step-drilldown-ui.md))
- **録画の枠をプロジェクト単位だけで持つ(11/11 まで)** — 一部のステップ(表紙の画像など)だけ余白なしにできない
- **プレビューのドラッグは全体を変え、ステップの上書きは設定パネルからだけにする** — テロップのドラッグ(常にステップ)と規則が食い違う
- **余白が違うステップの切れ目で枠を動きで変化させる** — フェード・フラッシュ以外のアニメーションは持たない(要件 3.2)。切れ目で急に変わるのが気になるならフェードを使う
- **「余白あり/全画面」などのモードを残す** — 余白の量で表せる。名前が実態(画面を小さくする)と合いにくい
- **録画の配置を中心と幅(`layout.video`)で持つ(10/29 の案)** — 上下左右を別々に決められない。縦横比を変える操作(切り取り)を表せない
- **四隅のハンドルで反対側の角を固定する方式だけにする(図形編集ソフトの既定)** — ユーザーの指定で中心固定を既定にし、隅固定は切り替えで選べるようにした
- **テロップの箱を「録画に重なるときだけ」自動で付ける(旧既定)** — 意図せず箱が付く。ユーザーの指定で手動にした
- **縦横比を変えたら録画を引き伸ばす** — 歪む。切り取りにする
- **余白を出力の高さだけに対する割合で持つ** — 左右の値が出力の縦横比に依存して分かりにくい
