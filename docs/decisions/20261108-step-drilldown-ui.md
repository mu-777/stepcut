# 設定はサムネイル列 + 右の設定パネル(ステップの詳細)にまとめる(2026-11-08 決定)

編集画面の設定の置き場所についての決定。左カラム(プロジェクト・ステップ一覧)と右カラム(選んだものの設定)に分かれていた設定を、左のサムネイル列と右の設定パネル 1 か所にまとめる。M2 でポインター・蛍光ペン・図形を足す前に、置き場所の型を決めておく。タイムライン・プレビュー・再生操作の決定は [20261029-timeline-ui.md](20261029-timeline-ui.md)。設定の関係の図は [../settings-map.html](../settings-map.html)。

## 決定

- 画面は左から「サムネイル列 | プレビューとタイムライン | 設定パネル」(PowerPoint・Keynote のスライド一覧・スライド・書式パネルと同じ並び)。対象をサムネイル列かタイムラインで選び、真ん中のプレビューで基本の編集をし、細かい数値は右の設定パネルで直す、という左から右への流れにする。サムネイル列と設定パネルの幅はドラッグで変えられる(サムネイルは列の幅に合わせて大きくなる)
- 階層は「全体 → ステップ → 要素(テロップ・読み上げ・ズーム)」。設定パネルはこの階層で切り替え、データの種類ごとのアイコンは置かない
- **サムネイル列**(ステップの一覧の代わり。既定の幅は文が横に出る 220px)
  - いちばん上に「全体」。押すと全体の設定
  - ステップごとに番号付きのサムネイル。押すとプレビューがそのステップの頭へ移り、設定パネルがそのステップの詳細になる。直しているステップは枠の色、再生位置のステップは番号の色で示す
  - サムネイルの横に ID・長さとテロップの文(列の幅に合わせて折り返し、3 行まで)を出す。列が狭い(170px 以下)とサムネイルだけを列の幅いっぱいに出す。文が隠れている・切れているときは、マウスを重ねると横に全文を出す
  - 右クリックで並べ替え・複製・次とまとめる・削除。いちばん下の ＋ で録画を追加
- **プレビューの真下の帯**: 枠の編集中でなければ「テロップ」(そのステップのテロップの文をその場で入力)と「＋ ズーム」(再生位置にズームを足して範囲を描く)を出す。基本の編集はプレビューから始められる
- **ステップの詳細**: 見出しに「ステップ N ID」と ◀ ▶(隣のステップへ)。その下に開け閉めできる欄を 3 つ
  - **録画・速度**: 録画・In/Out・速度・録画の音・保持。既定で閉じ、閉じていても長さ(と速度)を見出しに出す
  - **文**: テロップと読み上げ(複数。声・速さは 1 つずつ)
  - **ズーム**: このステップのズームの一覧。選んだズームはその場で開いて数値を出す。追加ボタン
  - 欄の開閉はステップをまたいで覚える。要素を選ぶとその欄が開き、その要素を強調する
- **全体の設定**: 出力・背景・余白(録画の枠)・影と、全ステップ共通のテロップの見た目・位置、声・速さ・音量・辞書
- ステップの詳細のテロップの位置には「共通の設定 ›」(個別に設定していなければ)を出し、押すと全体の設定のテロップの見た目の欄へ移る
- タイムライン・プレビューで要素を選ぶと、それを直す画面に切り替わる(録画の枠 → 全体の設定、それ以外 → そのステップの詳細)
- 設定パネルで直すステップは、選んだ要素のステップ。なければ再生位置のステップ
- プレビューでのテロップのドラッグは、開いている画面によらず常にそのステップの個別の値にする。全ステップ共通にするのは、ステップの詳細の「この位置を共通にする」(この位置・幅を共通にし、このステップの個別の値を消す)か、全体の設定の数値
- 長い説明文(ズームの帯の意味など)はパネルに置かない。README とキー操作の一覧が持つ
- ポインター・蛍光ペン・図形は M2 でステップの詳細の欄として足す

## 理由

- 左カラムは「プロジェクト」のボタンとステップ一覧だけで、タイムラインの映像の段と中身が重なっていた。設定が左右に分かれ、目が往復していた
- 右カラムは、ズームを 1 つ選んでもステップの全項目が開いたまま並び、選んだ所に色が付くだけだった。M2 の要素が加わるとさらに伸びる
- 片側だけで設定が完結する形は、画面録画の編集アプリで一般的(ユーザーの指摘)
- 選ぶ(左)→ 見て直す(真ん中)→ 数値で詰める(右)と、操作の順に左から右へ並ぶ。プレビューで済む編集(テロップの文・位置、ズームの範囲、録画の枠)が多く、設定パネルは細かい調整のときだけ見ればよい(ユーザーの指摘)
- 「ステップ一覧 → ステップの詳細」の階層は、このアプリのデータの形(ステップ単位)と同じ。パーツ別のアイコンより、どのステップを直しているかが見出しで分かる
- サムネイル列なら一覧と詳細が同時に見え、詳細にパネルの幅を全部使える。文はサムネイルの横に出し、狭めてもマウスを重ねれば読める
- テロップと読み上げは、読み上げが既定でテロップの文を読むので同じ欄(ユーザーの指摘)
- 全ステップ共通の値をステップの詳細に混ぜると、どこまでがこのステップの値かが分からない。全体の設定に分け、ステップ側からは行き先だけを示す
- データの形(ステップ単位、時刻はステップ内、座標は画面側と映像側)は変えない。UI の置き場所だけの変更

7 案をモックで触って比べ、サムネイル列(案 C)と掘り下げの詳細(案 A)の組み合わせを選んだ。

## 不採用案と理由(逆戻りガード)

- **左に全体のツリー(ステップ一覧)、右にインスペクター(Unity 型)のまま** — 左右の往復と右の長さが残る
- **サムネイル列のすぐ右に設定パネルを置く(サムネイル列 | 設定パネル | プレビュー)** — 一覧と詳細は近いが、プレビューが一覧と設定の間にないため「選ぶ → 見て直す → 詰める」の流れにならない。プレビューでの編集のたびに目が左へ戻る(ブランチ ui-step-drilldown で実装して比べた)
- **アイコン列でパーツ(全体・ステップ・文・ズーム)を切り替える** — どのステップを直しているかが見えにくく、文のパネルにステップ個別と全ステップ共通が混ざった(ブランチ ui-side-panel で実装して比べた)
- **一覧と詳細を切り替える掘り下げ(一覧の行を開くと詳細、‹ で戻る)** — 詳細を開いている間は一覧が見えない。サムネイル列で解決
- **アコーディオン(一覧の行の下に詳細を開く)** — 詳細が長いと下のステップが押し出され、開く行を変えるたびに位置がずれる
- **詳細をタブ(録画・速度 / 文 / ズーム)で切り替える** — 文とズームを行き来するたびにタブを押す。開け閉めできる欄なら同時に見られる
- **パネルに一覧を置かない(タイムラインを一覧とみなし、パンくずで階層を示す)** — テロップの文で探すのや並べ替えがやりにくい
- **ツリー + インスペクター(左に縦に積む)** — 情報量が多く、設定欄が狭い
- **共通の値をその種類の欄の下(ステップの詳細の中)に置く** — ステップ個別の値と同じ並びに混ざる
- **プレビューのテロップのドラッグで、開いている設定に応じて共通の位置も変える** — 行き先が画面から読めない。ドラッグは常に個別、共通にするのはボタン

## 前提と再検討の条件

- ステップが数十を超えてサムネイルで探しにくくなったら、テロップの文での絞り込みを足す
- ステップごとに録画の枠の位置を変えたくなったら、録画・速度の欄に「このステップだけ」を足す(今は全体のみ)
- タイムラインを全幅にする(パネルをプレビューの横だけにする)かは未決。今はサムネイル列とパネルを上から下まで通している
