# 公開ライセンスは Apache-2.0(2026-10-26 決定)

このアプリの公開ライセンスと、それに伴う依存ライブラリの制約についての決定。

## 決定

Apache-2.0 で公開する。GPL など Apache-2.0 と両立しないライセンスの依存は入れない。

## 理由

無償で商用利用できるライセンスにするため。

## 不採用案と理由(逆戻りガード)

- **GPL 系の既存エディタ(Shotcut 等)をベースにする** — GPLv3 になり公開ライセンスと両立しない
- **Remotion を描画・書き出しに使う** — 一定規模以上の企業利用に有償ライセンスが要る(https://remotion.dev/pricing)

## 前提と再検討の条件

GPL の依存なしに必須機能(特にエンコード)が実現できないと分かったら見直す。
