# 背景は色・グラデーション・画像の 1 項目、映像の配置は中心と幅で持つ(2026-10-29 決定)

レイアウトの背景(LAY-04、U-02)と、枠付きでの映像の位置と大きさ(LAY-08)をプロジェクトファイルでどう持つか、既定値をどうするかの決定。

## 決定

- `layout.background` は 3 種類のどれか: 色の文字列 / `{ "gradient": { angle, colors } }` / `{ "image": "preset:<名前>" | ファイルパス }`。従来の色の文字列はそのまま使える
- 既定はプリセット画像 `preset:default`(青紫系のぼかし)。黒ではドロップシャドウが見えないため
- プリセット画像は 6 種(default / sunset / mint / ocean / graphite / paper)。画像ファイルは同梱せず、コードでグラデーションとぼかした円を描いて作る
- グラデーションは線形のみ、2〜4 色を等間隔。角度は CSS と同じ向き
- 背景は枠付き・全画面の両方に効く(全画面では映像の縦横比が出力と違うときの余白に見える)
- 映像の配置は `layout.video: { x, y, width }`。`x` / `y` は中心(出力に対する割合)、`width` は出力の幅に対する割合。高さはソースの縦横比で決まる。未指定なら従来の自動配置
- プレビューでは映像をクリックして選び、本体のドラッグで移動、角のドラッグで縦横比を保って拡大縮小する。移動では枠の中心を出力の縦横の中心線(と、帯より上の領域の縦の中心)に吸着する。Alt を押している間は吸着しない

## 理由

- 背景を 1 項目にすると「どれが効いているか」が JSON を見て一意に分かる。別々の項目にすると優先順位を覚える必要があり、AI の編集で矛盾した状態を作りやすい
- プリセットをコードで描くと、出力解像度に合わせて劣化なく作れ、画像ファイルのライセンス(C3)の確認が要らない
- 映像の位置を中心で持つと、縦横比の違う録画を混ぜても中心がそろう。幅だけを持てば縦横比が崩れた状態を表せない

## 不採用案と理由(逆戻りガード)

- **背景画像・グラデーションを `background` と別の項目にする** — 優先順位が暗黙になる
- **プリセット画像を PNG で同梱する** — 出力解像度ごとに劣化し、ライセンスの確認が要る
- **映像の位置を左上の座標と幅・高さで持つ(図形編集ソフトの数値入力と同じ)** — 高さを持つと縦横比の崩れを表せてしまう。録画の縦横比が変わると位置がずれる
- **円形グラデーション** — C7。必要ならプリセットで足りる

## 前提と再検討の条件

- 既定を画像に変えたため、背景を書いていない既存のプロジェクトは見た目が変わる(M1 段階なので許容。ユーザー判断)
- プリセットの見た目は仮。実際の手順書動画で合わないものがあれば差し替える
