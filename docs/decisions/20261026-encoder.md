# mp4 書き出しは OS / ハードウェアのエンコーダーを使う(2026-10-26 決定)

H.264/AAC の mp4 を書き出すエンコーダーの選択。ライセンス(Apache-2.0)と特許への配慮が主な制約。

## 決定

OS またはハードウェアのエンコーダーを使う。ハードウェアエンコーダーがない環境の代替手段は未決(要件 T-02)。

## 理由

- GPL のエンコーダー(x264 など)を同梱すると Apache-2.0 での公開と両立しない(C3)
- H.264/AAC の特許への配慮として、OS 側のエンコーダーに任せる方式を基本にする(C4)。法的な確認は別途必要(要件 T-03)
- OpenScreen が WebCodecs で GPU エンコードし、CPU へ自動で切り替える前例がある

## 不採用案と理由(逆戻りガード)

- **FFmpeg + x264 を同梱(Shotcut 方式)** — x264 が GPL
- **クラウドでエンコード** — ローカル完結(C1)とランニングコストゼロに反する

## 前提と再検討の条件

- UI 基盤(Electron / Tauri、要件 T-01)の選定で WebCodecs が使えない環境があれば、エンコード経路を見直す
- 特許の法的確認(T-03)で OS エンコーダー利用でも問題があると分かれば見直す
