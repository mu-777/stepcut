# 設定は左のアイコン列 + 設定パネル 1 か所にまとめる(2026-11-08 決定)

編集画面の設定の置き場所についての決定。左カラム(プロジェクト・ステップ一覧)と右カラム(選んだものの設定)に分かれていた設定を、左のアイコン列と設定パネルにまとめる。M2 でポインター・蛍光ペン・図形を足す前に、置き場所の型を決めておく。タイムライン・プレビュー・再生操作の決定は [20261029-timeline-ui.md](20261029-timeline-ui.md)。設定の関係の図は [../settings-map.html](../settings-map.html)。

## 決定

- 画面は左から「アイコン列 | 設定パネル | プレビューとタイムライン」。右カラムはなくす。パネルの幅はドラッグで変えられる
- アイコンはデータの種類ではなく「一緒に直すもののまとまり」で分ける。今は 4 つ
  - **全体**: 出力・背景・余白(録画の枠)・影。どれも全ステップに効く
  - **ステップ**: ステップの一覧(番号・長さ・テロップの文。並べ替えなどは右クリック)と、録画・In/Out・速度・録画の音・保持
  - **文**: そのステップのテロップと読み上げ(複数)。下に全ステップ共通のテロップの見た目・位置、声・速さ・音量・辞書
  - **ズーム**: 選んだズームだけを出す。選んでいなければ全ズームの一覧(選ぶとその区間へ移って編集を始める)と追加ボタン
- まとまりの基準: 一方の値がもう一方の既定になるもの(テロップの文 → 読み上げの文)は同じまとまり。同じ場所で作るもの(クリップの上で作る保持)は同じまとまり。それ以外はタイムラインの段ごと
- タイムライン・プレビューで要素を選ぶと、その要素を直すアイコンに切り替わる(録画の枠 → 全体、テロップ・読み上げ → 文、ズーム → ズーム、クリップ・保持 → ステップ)。アイコンを押しても選択は変えない
- パネルで直すステップは、選んだ要素のステップ。なければ再生位置のステップ
- 各パネルは「選んでいるもの」を上、「全ステップ共通」を下に置く。共通の値はその種類のパネルに置き、全体のパネルには置かない
- プレビューでのテロップのドラッグは、開いているパネルによらず常にそのステップの個別の値にする。全ステップ共通にするのは、文のパネルの「この位置を共通にする」(この位置・幅を共通にし、このステップの個別の値を消す)か、共通の欄の数値
- 読み上げの声・速さは読み上げ 1 つずつの欄に置く
- 長い説明文(ズームの帯の意味など)はパネルに置かない。README とキー操作の一覧が持つ
- ポインター・蛍光ペン・図形は M2 で「注釈」のアイコンとして足す。中身ができるまでアイコンは出さない

## 理由

- 左カラムは「プロジェクト」のボタンとステップ一覧だけで、タイムラインの映像の段と中身が重なっていた。設定が左右に分かれ、目が往復していた
- 右カラムは、ズームを 1 つ選んでもステップの全項目(テロップ・読み上げ・音・保持・ズーム)が並び、選んだ所に色が付くだけだった。M2 の要素が加わるとさらに伸びる
- 片側のアイコン列 + パネルは、画面録画の編集アプリで一般的な形で、片側だけで設定が完結する(ユーザーの指摘)
- テロップと読み上げを別のアイコンにすると、文を直すたびに行き来する(ユーザーの指摘)
- テロップのドラッグの行き先が開いている設定で変わる作りは、どちらに効くかが画面から読めなかった
- データの形(ステップ単位、時刻はステップ内、座標は画面側と映像側)は変えない。UI の置き場所だけの変更

## 不採用案と理由(逆戻りガード)

- **左に全体のツリー(ステップ一覧)、右にインスペクター(Unity 型)のまま** — 考え方は正しいが、ツリーの役割はタイムラインが持っている。左右の往復と右の長さが残る
- **アイコンをデータの種類ごとに分ける(テロップ・読み上げを別)** — 読み上げは既定でテロップの文を読むので、一緒に直すことが多い
- **選んだ要素 1 つだけを出す(テロップを選んだら読み上げは出さない)** — 上と同じ理由。「選んだもののまとまり」を出す
- **共通の値を全体のパネルに集める** — テロップの見た目を変えるたびに全体へ移ることになる。その種類のパネルの下に置く
- **ステップ一覧をなくす** — 一覧はテロップの文で全体の流れを読むのに使える。ステップのパネルの上に置く
- **プレビューのテロップのドラッグで、開いている設定に応じて共通の位置も変える** — 行き先が画面から読めない。ドラッグは常に個別、共通にするのはボタン
- **注釈のアイコンを先に出しておく** — 中身のないパネルになる。M2 で入れる

## 前提と再検討の条件

- アイコンが増えて列に収まらなくなったら、まとまりを見直す
- ステップごとに録画の枠の位置を変えたくなったら、ステップのパネルに「このステップだけ」を足す(今は全体のみ)
- タイムラインを全幅にする(パネルをプレビューの横だけにする)かは未決。今はパネルを上から下まで通している
