# メインプロセス・検証・CLI のメッセージの言語(2026-11-16 決定)

画面(レンダラー)の外で作る利用者向けの文言を扱う。対象は、メインプロセスのエラー・ダイアログ・メニュー、プロジェクトの検証、読み上げの案内、CLI の出力。これまでは日英を併記した文や日本語だけの文を直書きしていて、画面の言語の設定(NF-07)が効いていなかった。

## 決定

- **画面に出るエラー・検証・案内はコードで返し、画面で訳す。** `src/shared/messages.ts` の `Msg`(`code` と `params`)と `AppError` を使う。英語の文は `MESSAGE_EN`(同じファイル)、日本語の文は `src/renderer/src/i18n.ts` の `MESSAGE_JA` に置き、`msgText` / `errorText` で画面の言語にする。値が `Msg` なら入れ子にして同じ言語で文にする(OS の声で代わりに読んだ知らせに、使えなかった理由を入れるなど)
- **IPC はメッセージに印を付けて渡す。** Electron の `invoke` はエラーの `message` しか渡さない([Electron: ipcRenderer.invoke](https://www.electronjs.org/docs/latest/api/ipc-renderer#ipcrendererinvokechannel-args))。メインの `handle()` は `ipcMain.handle` を包み、`AppError` を `stepcut-msg:{json}` の message にして投げる。画面の `decodeError` は印を戻し、Electron の前置き(`Error invoking remote method …`)も外す。`AppError` 以外のエラー(OS・Node・fetch)は訳さずに元の文のまま出す
- **ネイティブのダイアログとメニューはメインの小さな辞書で訳す**(`src/main/i18n.ts`)。言語はアプリの設定で、auto なら `app.getLocale()`。設定で言語を変えたらメニューを作り直す
- **プロジェクトの検証**(`core/validate.ts`)は `{ path, code, params }` を返す。`path` は訳さない。Zod の形の検証の文は `z.config` の言語(`zod/v4/locales` の `ja` / `en`)で、画面は画面の言語に合わせる
- **CLI は英語に固定する。** メインの CLI は `formatEn` を使う。書き出しなどを行う非表示の画面(`?mode=export`)は言語を `en` にしてから動くので、画面側で作る警告・エラーも英語になる。`validate --json` の `errors[]` / `warnings[]` は `{ path, code, message }`(`message` は英語)

## 理由

- 画面の言語と同じ辞書(画面側)で訳すと、言語の切り替えにそのまま追従する。辞書がメインと画面に分かれるのはダイアログ・メニューの 20 語ほどに限られる
- CLI の結果は主に AI とスクリプトが読む。言語を固定し、`code` で機械的に見分けられるようにする。`message` は残すので、以前の結果の形を読む側は壊れない(中身は日本語から英語に変わった)
- `MESSAGE_JA` を `Record<MessageCode, string>` にして、訳の抜けを型チェックで落とす

## 不採用案と理由(逆戻りガード)

- **日英の併記を残す** — 長く読みにくい。画面の言語の設定が効かず、NF-07 に合わない
- **すべてメインで訳す(メインに完全な辞書を持つ)** — 画面と同じ文言の辞書が 2 つになる。画面だけで言語を切り替えたときにメインの状態とずれる
- **検証のメッセージを英語に固定する** — 日本語の画面でも英語が出て、NF-07(日本語にも対応)に合わない
- **検証で両方の言語の文を持たせ、使う側で選ぶ** — 訳が画面の辞書と別の場所に散る
- **IPC のエラーを戻り値(`{ error }`)で返す** — すべての IPC の戻り値の形と呼び出し側を変える必要がある。message に印を付ければ、呼び出し側は `errorText` を通すだけで済む

## 前提と再検討の条件

- Electron の `invoke` がエラーの message だけを渡す挙動を前提にしている。エラーの独自のプロパティが渡るようになったら、印は要らなくなる
- 3 つ目の言語を足すときは、`MESSAGE_JA` と同じ形の辞書を足し、`setLanguage` と `setMainLanguage` の選び方を広げる
