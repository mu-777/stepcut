録画を、手順が伝わる動画に。

画面録画をステップに切り分け、テロップ・読み上げ・ズームを付けて mp4 に書き出す、Windows 用の無料アプリです。

Windows 版をダウンロード GitHub で見る

Windows 10 / 11 ・ 無料 ・ Apache-2.0

録っただけの画面が、こう変わります

→

できること

ステップに切り分け

1 本の録画を、手順ごとの場面に分けます。

テロップ

画面の上の文字を、その場で書き換えます。

読み上げ

テロップの文が、そのまま音声になります。

ズーム

見せたい範囲を枠で囲むと、そこに寄ります。

ポインター・図形

ポインター、蛍光ペン、矢印、四角を重ねます。

mp4 書き出し

どこでも再生できる動画ファイルになります。

安心して使える理由

ネット接続なしで使える

録画も編集内容も PC の外に出ません。社内システムの手順書にも使えます。

無料・オープンソース

Apache-2.0。アカウント登録も課金もありません。

AI でも編集できる

編集内容はテキスト(JSON)のファイル。Claude Code にテロップの下書きを頼めます。

使い方

  1. STEP 1

    録画を入れる

  2. STEP 2

    切って、説明を付ける

  3. STEP 3

    書き出す

ダウンロード

Windows 版をダウンロード

Windows 10 / 11 ・ インストーラ版と、インストール不要の portable 版があります

初回の起動時に「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を選んでください(コード署名をしていないためです)。
