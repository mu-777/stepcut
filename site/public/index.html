How it works

Four tasks take you from a recording to an export. This video was also made with StepCut.

STEP 1

Add a recording

Open an mp4 you recorded. You can add images too.

STEP 2

Split into steps

Split where the explanation changes. Only the parts you need become steps.

STEP 3

Write captions

Write one sentence per step. It is read aloud. Add a zoom or a pointer where you want to draw attention.

STEP 4

Export

You get an mp4.

FAQ

Is it free?

Yes. It is open source under Apache-2.0, with no account and no payment.

Are my recordings or projects sent anywhere?

Not with the default settings. Only if you choose Azure AI Speech for narration is the text to be read sent to that service.

Can I choose the narration voice?

Yes. Besides the built-in Windows voices, StepCut can connect to Azure AI Speech and VOICEVOX. You can set the voice and speed for the whole project or for each step.

Does it run on Mac?

Windows only for now. A Mac version is planned.
