# レンダラーの CSS

- styles.css は 1 ファイルで全体に効く。`.left` `.right` `.selected` のような短い汎用名を、レイアウト用と部品用で使い回さない。部品の修飾子(`.tl-handle.left` など)にレイアウト用の規則が当たり、余白や背景が付いて部品が隠れた例がある。レイアウトの要素には `left-pane` のように固有の名前を付ける
- タイムラインの横位置は必ず `時刻 × pps` で出す(目盛り・クリップ・帯・再生ヘッドを同じ変換にそろえる)。別の部品(range 入力など)で時刻を表すとずれる
- grid・flex の子要素は既定で `min-width: auto`(中身の幅より縮まない)。プレビューやタイムラインのように中身の幅を自分で決める部品を入れる列は、子に `min-width: 0` を付ける。付けないと列が広がり、隣のカラムに重なって操作できなくなる
