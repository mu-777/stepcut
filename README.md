# 手順書動画エディタ(仮称) / screen-annotator

録画済みの画面録画から、PC アプリの手順書動画(mp4)を作るローカルデスクトップアプリ。

- 1 本の画面録画をステップ(場面)に切り分け、各ステップにテロップ・読み上げ・ズーム・ポインター・蛍光ペンを付ける
- 編集内容はテキスト(JSON)のプロジェクトファイルに保存し、人手でも AI でも編集できる
- ネット接続なしで全機能が動く
- 対応 OS: Windows(Mac は移植予定)

開発中。要件は [docs/requirements.md](docs/requirements.md)、決定記録は [docs/decisions/](docs/decisions/) を参照。
