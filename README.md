# StepCut

Turn recordings into step-by-step videos, driven by captions.

録画済みの動画(画面録画など)をステップに切り分け、テロップを軸に手順を見せる動画(mp4)を作るローカルデスクトップアプリ。

- 1 本の画面録画をステップ(場面)に切り分け、各ステップにテロップ・読み上げ・ズームと、オブジェクト(ポインター(蛍光ペンを含む)・四角(画像を入れられる)・矢印・テキスト)を付ける
- 編集内容はテキスト(JSON)のプロジェクトファイルに保存し、人手でも AI でも編集できる
- ネット接続なしで全機能が動く
- 対応 OS: Windows(Mac は移植予定)

開発中(M1)。要件は [docs/requirements.md](docs/requirements.md)、決定記録は [docs/decisions/](docs/decisions/) を参照。

## 開発

Node.js のバージョンは `.node-version` で指定する(CI も同じファイルを読む)。バージョンマネージャ [fnm](https://github.com/Schniz/fnm) を使うと、このフォルダに入ったときに自動で切り替わる。

```powershell
winget install Schniz.fnm
# PowerShell のプロファイル($PROFILE)に 1 行追加し、ターミナルを開き直す
Add-Content $PROFILE 'fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression'
fnm install        # リポジトリ直下で実行。.node-version のバージョンを入れる
```

`npm run dev` では画面(src/renderer)の変更が再起動なしで反映される。main・preload の変更も自動で反映させるには `npx electron-vite dev -w`(保存のたびに再ビルドして再起動する)。


```bash
npm install
npm run dev        # 開発用に起動
npm run build      # out/ にビルド
npm start          # ビルド済みを起動
npm run check      # lint・型チェック・単体テスト・ビルド
npm run dist:win   # Windows 用のインストーラと portable 版を dist/ に作る(Windows 上で実行)
```

ロゴの元データは `assets/logo/`(SVG)。Windows のアイコン `build/icon.ico` は、`assets/logo/stepcut-icon.svg` を変えたときに `node scripts/make-icon.cjs` で作り直してコミットする(Playwright が要る)。

main への PR では GitHub Actions が Windows 版をビルドし、run の Artifacts(`stepcut-win`)に置く。

起動時にプロジェクトファイルを渡すと、それを開く: `npx electron . path/to/project.stepcut.json`

## 操作

画面は左からサムネイル列、プレビューとタイムライン、設定パネル。対象をサムネイル列かタイムラインで選び、プレビューで直し、細かい数値は右の設定パネルで詰める。プレビューの真下の帯は 2 段。上の段の「テロップ」でそのステップのテロップをその場で入力、「ズーム」で再生位置にズームを足して範囲を描ける。続く「ポインター・蛍光ペン・四角・矢印・テキスト・画像」で再生位置にオブジェクトを足せる(蛍光ペンは見た目を蛍光ペンにしたポインター、画像は先にファイルを選び、画像を入れた四角を作る)。再生中・枠の編集中は押せない。下の段は中心固定/隅固定などの状況に応じた操作と、プレビューの表示倍率。サムネイル列のいちばん上の「全体」で全体の設定(出力・背景・録画の枠・テロップの見た目・声・辞書。全ステップに効く)、ステップのサムネイルでそのステップの詳細(録画・速度 / 文 / ズーム / オブジェクトの開け閉めできる欄)を開く。「録画・速度」の見出しには長さが出て、左の列と同じ、保持(映像を止めるズーム・置いた保持・読み上げ待ち)を含むステップ全体の長さ。サムネイルの横に「ステップ N」・長さとテロップの文(3 行まで)が出る。ステップは画面ではすべて時間の順の番号(ステップ N)で呼ぶ(ファイルの中の id は画面に出さない)。列を狭めるとサムネイルだけになり、文はマウスを重ねると出る。タイムラインやプレビューで要素を選ぶと、それを直す画面に切り替わり、その欄が開く。パネルで直すステップは、選んだ要素のステップ(なければ再生位置のステップ)。パネルの境界はドラッグで幅を変えられる。キーのある操作は、右クリックメニューとボタンのツールチップにキーを表示する。キー操作の一覧は Ctrl+/ かヘッダーの右の ? で開く。設定パネルの見出しの右の山形のボタンで、欄をすべて閉じる。要素を選ぶと、その欄だけが開いてほかの欄は閉じる。

ヘッダー(メニューバーは出さない)はアイコン(ファイルと書き出しは文字も添える)で、左にファイル(新規・開く・保存のメニュー)・元に戻す/やり直し、ウィンドウの中央にプロジェクトの名前(未保存なら ●)、右にキー操作の一覧(?)・設定(歯車)・書き出し。名前をクリックすると名前を変えられる(保存済みならファイル名が変わる)。まだ保存していないプロジェクトで保存すると、先に名前を入れ、アプリの設定の保存先に保存する(保存先を決めていなければ保存先を尋ねる)。歯車はアプリの設定(言語、プロジェクトの保存先、キー操作の割り当て)で、プロジェクトのファイルには入らない。キー操作の割り当ては、キー操作の一覧の「キー操作を変更…」からも開ける。割り当てたいキーのボタンを押してから新しいキーを押す(同じキーがほかの操作にあればそちらを外す。ファイル・元に戻す・コピーなどの Ctrl のキーは変えられない)。知らせ(保存・書き出しの結果など)とプロジェクトの問題(検証のエラー・警告、読めない録画)はヘッダーの下の帯に出る。どちらも × で閉じられ、問題は中身が変わるとまた出る。録画・画像のファイルが見つからないときは、問題の行の「場所を選ぶ…」で選び直せる(素材のパスだけが変わり、ステップはそのまま)。開けなかったプロジェクトファイルは、ファイル名を添えて知らせる。ウィンドウの最小幅は、左右のパネルの最小幅に再生操作の帯が重ならずに並ぶ幅を足したもの。

既定のキー(Ctrl のキー以外はアプリの設定で変えられる)。再生速度(×0.5〜×3)は再生操作の欄で選ぶ。

| キー | 内容 |
|---|---|
| Space | 再生/停止 |
| ← / → | 1 秒移動(録画・ズームの枠を編集中は枠を 10px 動かす。Shift で 1px) |
| Shift+← / → | 1 フレーム移動 |
| ↑ / ↓ | 前/次のステップ境界へ |
| Home / End | 先頭/末尾 |
| S | 再生位置でステップを分割 |
| Z | 再生位置にズームを追加 |
| M | 消音 |
| F | プレビューの全画面表示 |
| C | 枠の拡大縮小の中心固定/隅固定を切り替える |
| Delete | 選んだ要素(ステップ・ズーム・保持・テロップ・読み上げ・オブジェクト)を削除 |
| Ctrl+C / Ctrl+X / Ctrl+V | 選んだズーム・読み上げ・オブジェクトをコピー・切り取りし、再生位置に貼り付ける(再生位置が始まりになる) |
| Ctrl+ホイール | タイムライン・プレビューの拡大縮小(カーソルのある側)。ボタンはタイムラインの左上の角と、プレビューの真下の帯の下の段の右 |
| Ctrl+/ | キー操作の一覧 |

タイムライン:
- 目盛り・レーンの空いているところ・レーンの下の空きのクリック・ドラッグでシークする。ステップの切れ目と各要素の始まり・終わりに吸着する(Shift で解除)。レーン上の要素(テロップ・読み上げ・ズーム・オブジェクト)はクリックで選んでも再生位置を動かさず、ダブルクリックで再生位置をその始まりへ移す(ズームのダブルクリックは枠の追加)。映像クリップは、再生位置がそのステップの外のときだけステップの始まりへ移す。横のホイールではその向きにスクロールする
- クリップ端のドラッグで In/Out、テロップ・読み上げ・ズームの帯のドラッグで時刻を変える。ズーム・読み上げ・オブジェクトの始まりを動かすと再生位置も合わせる(ズームの終わりを動かすと、映像を「止める」ズームは始まり、それ以外は終わりに合わせる。オブジェクトの終わりを動かすと終わりに合わせる)。読み上げ・ズーム・オブジェクトは Ctrl+クリックでまとめて選び、まとめてドラッグで動かせる(端のドラッグでは、選んだものすべての同じ側の端を同じだけ動かす)。映像のクリップには、ステップのフェードイン・フェードアウトの区間を黒の三角と斜めの線で示す。置いた保持は、ドラッグで位置、右端で長さを変える(再生ヘッドとステップの切れ目に吸着)
- テロップ・読み上げ・ズームのレーンをダブルクリックすると、その時刻に作る(すでにあれば選ぶ)。読み上げは 1 ステップに複数置ける
- ズームのレーンを空いているところからドラッグするとズームを作る。ズームの帯は拡大したまま保つ区間で、前後の斜めの部分が拡大・縮小の動き。ズームをクリックするとプレビューで範囲を編集する(編集中にタイムラインでシークしても編集を続け、再生を始めると終える)。ズームの帯をダブルクリックすると、その時刻に枠を足す
- オブジェクトの段には、ポインター・図形を出ている間の帯で並べる(時刻が重なるものは行を分ける)。帯のドラッグで移動、両端で出ている間を変える(右端を末尾まで伸ばすとステップの終わりまで)。ポインターの帯の中の明るい部分は、動く・線を引く区間。録画に追従する図形が録画の外にはみ出していると、帯が赤い縞になり「⚠ 録画外にはみ出し」と出る
- 右クリックで分割・保持・末尾に保持・次のステップとまとめる・このステップの録画の音を消す/鳴らす、ズーム・読み上げ・オブジェクトのコピー/切り取り/削除、読み上げの試聴、オブジェクトの複製/前面へ/背面へができる。ズーム・読み上げ・オブジェクトのレーンの空いた所の右クリックでは、その時刻に作る・貼り付ける。映像のレーンの空いた所の右クリックで末尾に、クリップの右クリックでそのステップの後ろに録画・画像を足す。画像のクリップは両端のドラッグで長さを変える。ステップの並び替えは左のサムネイルの右クリックから
- 映像の段の見出しのボタンで、録画の音を全体で消す・鳴らす(プレビューと書き出しの両方。全体で消すとどのステップも鳴らない)。録画の音を消したステップのクリップには印が出る

プレビュー:
- 右クリックで、クリックした点を中心にズームやオブジェクトを作る(「＋ ズーム」「＋ 四角」など)。録画の外(背景)で作った図形は画面に固定される。オブジェクトの上の右クリックでは、そのコピー・切り取り・複製・前面へ・背面へ・削除もできる
- 録画をクリックすると枠が出る。枠の中のドラッグで移動、四隅で縦横比を保って拡大縮小、四辺の中央で縦横比を変える(録画の端を切り取る)。中心線と画面の辺に吸着する(Alt で解除)。ドラッグでの移動では枠の大きさは変わらない。ズームの範囲も同じ操作(録画の内側だけを動く)で、枠の外のクリック(プレビューの外や再生ボタンも含む。設定パネル・タイムライン・映像の下の帯を除く)、再生の開始(Space を含む)か Esc で確定する
- ステップがないときは、プレビューの録画を置く場所の中央に出る「録画・画像を追加…」か、サムネイル列いっぱいに出る「＋ 録画・画像」で録画を追加できる(ステップがあるときは列の下端に同じボタンを出す)。画像(png・jpg・webp)も同じく足せて、止まった映像のステップ(既定 3 秒、音なし)になる。mp4・画像をサムネイル列にドロップしても追加できる(ステップがあるときも)
- 録画の枠(余白・切り取り・影)はステップごとに変えられる。プレビューで録画の枠を動かすと再生位置のステップだけが変わり、設定パネルの「録画の枠」の欄に「このステップだけ」と出る。全ステップにそろえるには「この枠を共通にする」、全体の枠に戻すには「全体の枠に戻す」を押す。全体の設定の「レイアウト」の値は、個別の枠を持たないステップに効く
- 録画の枠(余白)を変えると、位置を決めたテロップも枠との位置関係を保って動く(録画の下の余白の真ん中にあれば、余白が変わっても真ん中)
- テロップをドラッグして位置を変える(中央・録画の下の余白の中央・録画の下辺・画面の下辺に吸着)。ドラッグで変わるのはそのステップだけの位置で、全ステップ共通にするにはステップの詳細の「この位置を共通にする」を押す。PowerPoint と同じく、文字のクリックでその場で入力でき(ステップの詳細の入力欄と同じ値。Enter で改行、Esc か外のクリックで終える)、文字の外側の縁のクリックで枠を選ぶ。どちらもそのステップのテロップの設定へ移る。録画を追加したときと分割した後半には、空のテロップ(プレビューにだけ仮の文を出す)が付く
- Ctrl+ホイールかプレビューの真下の帯の −/%/+ で、プレビューだけを拡大縮小する(中ボタンのドラッグで表示位置を動かす。% を押すと全体表示)
- テロップを選ぶと左右の端に取っ手が出る。ドラッグで幅を変える(中心固定。録画と画面の左右の辺に吸着)
- 枠の編集中(四角・テキストを選んだときも)は、プレビューの真下の帯に「中心固定/隅固定」が出る(C キーでも切り替える)。ズームでは「再生位置に枠を追加」「◀ 枠 i/n ▶」「サイズを全枠でそろえる」も出る。枠(キーフレーム)を 2 つ以上置くと、枠と枠の間を一定の速さで移る。ほかの枠は点線で出し、クリックでその枠の編集に切り替える
- タイムラインのズームの帯の ◆ は枠。クリックでその枠を編集、ドラッグで時刻を変える、右クリックで削除
- オブジェクトはクリックで選ぶ(空いた所のクリックで選択を外す)。四角・テキストは録画の枠と同じ取っ手で動かし・大きさを変える。ポインター・矢印は両端の丸い取っ手で端を、線のドラッグで全体を動かす(ポインターの 1 は動き始め、2 は着く所)。ポインターは水平、矢印は 45 度ごとに吸着する(Alt で解除)。ズーム中も見えている位置のまま直せる。テキストをダブルクリックすると、設定パネルの文の入力欄へ移る
- 図形は設定パネルの「位置の基準」のボタンで「録画に追従(ズームと一緒に動く。録画の中だけに描く)」と「画面に固定(ズームしても動かず、背景や録画と背景にまたがる位置にも置ける)」を選べる。切り替えても見えている位置と大きさは変わらない。録画に追従する図形が録画の外にはみ出すと(はみ出た所は描かれない)、項目の見出しに「⚠ はみ出し」、位置の小見出しとオブジェクトの欄の見出しに ⚠ が出て、プレビューで選んだときの枠が赤になる
- ポインターの見た目は、設定パネルのアイコンのボタン(矢印のカーソル・丸・輪・蛍光ペン・画像)で選ぶ。その下の行が選んだ見た目の設定(大きさ・色・太さ・不透明度・画像)に変わる。蛍光ペンは動きに沿って線を引く
- 四角の線・塗りはチェックで出す・消す。四角には「画像を入れる…」で画像を入れられる(四角を画像の縦横比に合わせる)。線は画像の枠になり、透明な所には塗りが見える
- オブジェクトの時刻・出入り(すぐ・フェード・点滅。フェードは長さ、点滅は長さと回数も)・色や太さ・位置の数値は、設定パネルのオブジェクトの欄で直す。欄は始まりの時刻の順で、項目はいくつでも開いたままにできる(タイムライン・プレビューで選ぶとそれだけを開き、設定パネルで開いたものは足す)。停止中は、選んでいるオブジェクトをフェード・点滅で見えない時刻でも出す。点滅は「秒」の中で「回数」ぶん均等に点滅する(秒を出ている間と同じにすれば、出ている間ずっと点滅する)。開いた項目は「見た目」「時間」「位置」(普段は畳んである)に分かれ、見出しの右のアイコンで複製・前面へ・背面へ・削除。ステップを分割すると、分割点をまたいで出ているオブジェクトは前半のステップの終わりまで出る。全ステップ共通の見た目は全体の設定の「オブジェクトの見た目(共通)」

## プロジェクトファイル

仕様は [docs/project-format.md](docs/project-format.md)、JSON Schema は [docs/project.schema.json](docs/project.schema.json)。素材の録画はプロジェクトと同じフォルダかその下なら相対パスで保存する。

アプリはプロジェクトファイルの外部変更を検知して再読み込みする。未保存の変更があるときは、どちらを採用するか確認する。

## CLI

```bash
stepcut validate <project.json> [--json]
stepcut export <project.json> [--out <file.mp4>] [--json] [--result <file.json>]
stepcut frame <project.json> (--step <番号|id> [--time <秒>] | --at <秒>) [--source] [--out <file.png>] [--json] [--result <file.json>]
stepcut inspect <project.json> [--json] [--result <file.json>]
```

CLI はアプリの実行ファイルそのもの(Windows のインストーラの既定では `%LOCALAPPDATA%\Programs\StepCut\StepCut.exe`)。アプリを開いたままでも使える。

- 開発中は `npx electron . validate ...` のように実行する(`npm run build` の後)
- 終了コード: 0 = 成功、1 = 検証エラーまたは書き出し失敗、2 = 引数の誤り
- コマンドの名前が違うとき(最初の引数がコマンドでも `.json` でも既存のパスでもない)は、使い方を出して終了コード 2 で終わる(アプリの画面は開かない)
- `--json` は結果を JSON で標準出力に出す。`--result` は同じ JSON をファイルにも書く。`--out` `--result` `--step` `--time` `--at` は値が必須(値がなければ引数の誤り)
- `validate`(と、`export` などの最初の検証)は、素材に加えて背景・図形・ポインターの画像ファイルがあるかも確かめる(なければエラーで、`path` に場所が出る)
- `export` はウィンドウを表示せずに書き出す。`--out` を省くとプロジェクトと同じ場所に `.mp4` を作る。`output.srt` が true なら SRT も書く
- `frame` は 1 フレームを PNG にする。`--step`(1 始まりの番号かステップの id)と `--time`(ステップ内の出力時刻、既定 0)か、`--at`(全体の時刻)で指定する。既定は書き出しと同じ見た目で、結果の `geometry` で画像の点を映像側の座標に直せる(`x = view.x + (px − box.x) / scale`)。`--source` は素材のフレームをそのままの大きさで出す(画像のピクセル = 映像側の座標)。`--out` を省くとプロジェクトと同じ場所に作る。`--time` がステップの長さを超えると、末尾のフレームを出して `warnings` で知らせる
- `inspect` は計算後の時間を出す: ステップごとの開始・長さ・自動の保持・保持、読み上げの文と実際の長さ・開始・終わり、テロップ・ズーム・オブジェクトの出ている間、素材の大きさ。読み上げは実際に生成して測る(失敗したものは長さ 0 として警告)

## Claude Code から使う

このリポジトリは Claude Code のプラグインのマーケットプレイスを兼ねる。Claude Code で次を実行すると、スキル `/stepcut:edit-project` が入る(プロジェクトの編集を頼むと自動でも使われる)。

```text
/plugin marketplace add mu-777/screen-annotator
/plugin install stepcut@stepcut
```

- スキルは CLI を自動で探す(環境変数 `STEPCUT_CLI` → 前に覚えた場所 → インストーラの既定の場所 → PATH)。見つからなければ場所を聞き、次からはそれを使う
- スキルは同梱のスクリプト(`scripts/run-cli.sh`)経由で CLI を呼ぶ。読むだけの `validate` と `frame` は確認なしで実行し、`inspect` と `export` は確認が出る
- プロジェクトファイルがまだないときは、録画全体を 1 ステップにした仮のプロジェクトを書いてから `frame --source` で区切りを探す
- スキルは `inspect` で時刻、`frame --source` で座標を決めてから JSON を書き、`validate` と `frame` で確かめる

## 書き出し

- 映像は H.264。ハードウェアエンコーダーを優先し、使えなければソフトウェアで書き出して警告を出す
- 音声は AAC。使えない環境(Windows N エディションなど)では Opus で書き出して警告を出す
- 書き出し中は、ヘッダーの書き出しのボタンが「中止 n%」になる。押すと中止し、途中のファイルは残さない
- 書き出しが終わるとヘッダーの下の帯に知らせが出て、「フォルダーを開く」で書き出したファイルのフォルダーを開ける
- 読み上げは OS 標準の音声合成(Windows: WinRT の SpeechSynthesizer、Mac: `say`)。対応していない OS では無音で代替する
- VOICEVOX 互換エンジンと Azure AI Speech も使える。既定では使えず、アプリの設定(歯車)の「読み上げエンジン」で有効にする。有効にするときに、規約・料金はご自身の責任で確認する旨の確認が出る
  - VOICEVOX: エンジンはご自身で入れる(アプリには含まない)。エンジンの場所(既定 `http://127.0.0.1:50021`)と、起動していないときに起動するプログラムを指定できる
  - Azure AI Speech: ご自身の Azure の契約の鍵とリージョンを入れる。鍵はこのパソコンで暗号化して保存し、プロジェクトファイルには書かない。読み上げる文は Microsoft に送られ、料金はご自身に請求される
  - 使うエンジンは全体の設定の「読み上げ」で選ぶ(プロジェクトごと)。有効にしていないパソコンでプロジェクトを開くと、OS 標準の声で代わりに読む
  - 書き出しのときに、使ったエンジンの規約(と料金)を確認するよう知らせる
