# 手順書動画エディタ(仮称) / screen-annotator

録画済みの画面録画から、PC アプリの手順書動画(mp4)を作るローカルデスクトップアプリ。

- 1 本の画面録画をステップ(場面)に切り分け、各ステップにテロップ・読み上げ・ズームを付ける
- 編集内容はテキスト(JSON)のプロジェクトファイルに保存し、人手でも AI でも編集できる
- ネット接続なしで全機能が動く
- 対応 OS: Windows(Mac は移植予定)

開発中(M1)。要件は [docs/requirements.md](docs/requirements.md)、決定記録は [docs/decisions/](docs/decisions/) を参照。

## 開発

Node.js のバージョンは `.node-version` で指定する(CI も同じファイルを読む)。バージョンマネージャ [fnm](https://github.com/Schniz/fnm) を使うと、このフォルダに入ったときに自動で切り替わる。

```powershell
winget install Schniz.fnm
# PowerShell のプロファイル($PROFILE)に 1 行追加し、ターミナルを開き直す
Add-Content $PROFILE 'fnm env --use-on-cd --shell powershell | Out-String | Invoke-Expression'
fnm install        # リポジトリ直下で実行。.node-version のバージョンを入れる
```

`npm run dev` では画面(src/renderer)の変更が再起動なしで反映される。main・preload の変更も自動で反映させるには `npx electron-vite dev -w`(保存のたびに再ビルドして再起動する)。


```bash
npm install
npm run dev        # 開発用に起動
npm run build      # out/ にビルド
npm start          # ビルド済みを起動
npm run check      # lint・型チェック・単体テスト・ビルド
npm run dist:win   # Windows 用のインストーラと portable 版を dist/ に作る(Windows 上で実行)
```

main への PR では GitHub Actions が Windows 版をビルドし、run の Artifacts(`screen-annotator-win`)に置く。

起動時にプロジェクトファイルを渡すと、それを開く: `npx electron . path/to/project.sanno.json`

## 操作

画面は左からサムネイル列、プレビューとタイムライン、設定パネル。対象をサムネイル列かタイムラインで選び、プレビューで直し、細かい数値は右の設定パネルで詰める。プレビューの真下の帯の「テロップ」でそのステップのテロップをその場で入力、「＋ ズーム」で再生位置にズームを足して範囲を描ける。サムネイル列のいちばん上の「全体」で全体の設定(出力・背景・録画の枠・テロップの見た目・声・辞書。全ステップに効く)、ステップのサムネイルでそのステップの詳細(録画・速度 / 文 / ズームの開け閉めできる欄)を開く。サムネイルの横に「ステップ N」・長さとテロップの文(3 行まで)が出る。ステップは画面ではすべて時間の順の番号(ステップ N)で呼ぶ(ファイルの中の id は画面に出さない)。列を狭めるとサムネイルだけになり、文はマウスを重ねると出る。タイムラインやプレビューで要素を選ぶと、それを直す画面に切り替わり、その欄が開く。パネルで直すステップは、選んだ要素のステップ(なければ再生位置のステップ)。パネルの境界はドラッグで幅を変えられる。キーのある操作は、右クリックメニューとボタンのツールチップにキーを表示する。キー操作の一覧は Ctrl+/ かプレビューの真下の帯の ? で開く。設定パネルの見出しの右の山形のボタンで、欄をすべて閉じる。要素を選ぶと、その欄だけが開いてほかの欄は閉じる。

ヘッダー(メニューバーは出さない)は、左にファイルの操作(新規・開く・保存・名前を付けて保存)・録画を追加・元に戻す/やり直し、真ん中にプロジェクトの名前(未保存なら ●)とフォルダー、右に設定・書き出し。「設定」はアプリの設定(言語、プロジェクトの保存先)で、プロジェクトのファイルには入らない。

| キー | 内容 |
|---|---|
| Space | 再生/停止 |
| J / K / L | 逆方向/停止/再生(連打で ×2、×3。再生速度の欄では ×0.5〜×3) |
| ← / → | 1 秒移動(録画・ズームの枠を編集中は枠を 10px 動かす。Shift で 1px) |
| Shift+← / → | 1 フレーム移動 |
| ↑ / ↓ | 前/次のステップ境界へ |
| Home / End | 先頭/末尾 |
| S | 再生位置でステップを分割 |
| Z | 再生位置にズームを追加 |
| M | 消音 |
| F | プレビューの全画面表示 |
| Delete | タイムラインで選んだ要素(ステップ・ズーム・保持・テロップ・読み上げ)を削除 |
| Ctrl+C / Ctrl+V | 選んだズームをコピーし、再生位置に貼り付ける |
| Ctrl+ホイール | タイムライン・プレビューの拡大縮小(カーソルのある側)。ボタンはタイムラインの左上の角と、プレビューの真下の帯の右 |
| Ctrl+/ | キー操作の一覧 |

タイムライン:
- 目盛りや空いているところのクリック・ドラッグでシークする。ステップの切れ目と各要素の始まり・終わりに吸着する(Shift で解除)
- クリップ端のドラッグで In/Out、テロップ・読み上げ・ズームの帯のドラッグで時刻を変える。置いた保持(静止)は、ドラッグで位置、右端で長さを変える(再生ヘッドとステップの切れ目に吸着)
- テロップ・読み上げ・ズームのレーンをダブルクリックすると、その時刻に作る(すでにあれば選ぶ)。読み上げは 1 ステップに複数置ける
- ズームのレーンを空いているところからドラッグするとズームを作る。ズームの帯は拡大したまま保つ区間で、前後の斜めの部分が拡大・縮小の動き。ズームをクリックするとプレビューで範囲を編集する
- 右クリックで分割・静止(保持)・末尾で静止・次のステップとまとめる・ズームの追加/コピー/貼り付け・読み上げの試聴ができる。ステップの並び替えは左のサムネイルの右クリックから

プレビュー:
- 右クリックで、クリックした点を中心にズームを作る
- 録画をクリックすると枠が出る。枠の中のドラッグで移動、四隅で縦横比を保って拡大縮小、四辺の中央で縦横比を変える(録画の端を切り取る)。中心線と画面の辺に吸着する(Alt で解除)。ドラッグでの移動では枠の大きさは変わらない。ズームの範囲も同じ操作(録画の内側だけを動く)で、枠の外のクリック(プレビューの外やタイムライン・再生ボタンも含む。設定パネルと映像の下の帯を除く)、再生の開始か Esc で確定する
- ステップがないときは、録画を置く場所のダブルクリックか、サムネイル列いっぱいに出る「＋ 録画を追加」で録画を追加できる。mp4 をサムネイル列にドロップしても追加できる(ステップがあるときも)
- テロップをドラッグして位置を変える(中央・録画の下の余白の中央・録画の下辺・画面の下辺に吸着)。ドラッグで変わるのはそのステップだけの位置で、全ステップ共通にするにはステップの詳細の「この位置を共通にする」を押す。PowerPoint と同じく、文字のクリックでその場で入力でき(ステップの詳細の入力欄と同じ値。Enter で改行、Esc か外のクリックで終える)、文字の外側の縁のクリックで枠を選ぶ。どちらもそのステップのテロップの設定へ移る。録画を追加したときと分割した後半には、空のテロップ(プレビューにだけ仮の文を出す)が付く
- Ctrl+ホイールかプレビューの真下の帯の −/%/+ で、プレビューだけを拡大縮小する(中ボタンのドラッグで表示位置を動かす。% を押すと全体表示)
- テロップを選ぶと左右の端に取っ手が出る。ドラッグで幅を変える(中心固定。録画と画面の左右の辺に吸着)
- 枠の編集中は、プレビューの真下の帯に「中心固定/隅固定」が出る。ズームでは「再生位置に枠を追加」「◀ 枠 i/n ▶」「サイズを全枠でそろえる」も出る。枠(キーフレーム)を 2 つ以上置くと、枠と枠の間を一定の速さで移る。ほかの枠は点線で出し、クリックでその枠の編集に切り替える
- タイムラインのズームの帯の ◆ は枠。クリックでその枠を編集、ドラッグで時刻を変える、右クリックで削除

## プロジェクトファイル

仕様は [docs/project-format.md](docs/project-format.md)、JSON Schema は [docs/project.schema.json](docs/project.schema.json)。素材の録画はプロジェクトと同じフォルダかその下なら相対パスで保存する。

アプリはプロジェクトファイルの外部変更を検知して再読み込みする。未保存の変更があるときは、どちらを採用するか確認する。

## CLI

```bash
screen-annotator validate <project.json> [--json]
screen-annotator export <project.json> [--out <file.mp4>] [--json] [--result <file.json>]
```

- 開発中は `npx electron . validate ...` のように実行する(`npm run build` の後)
- 終了コード: 0 = 成功、1 = 検証エラーまたは書き出し失敗、2 = 引数の誤り
- `--json` は結果を JSON で標準出力に出す。`--result` は同じ JSON をファイルにも書く
- `export` はウィンドウを表示せずに書き出す。`--out` を省くとプロジェクトと同じ場所に `.mp4` を作る。`output.srt` が true なら SRT も書く

## 書き出し

- 映像は H.264。ハードウェアエンコーダーを優先し、使えなければソフトウェアで書き出して警告を出す
- 音声は AAC。使えない環境(Windows N エディションなど)では Opus で書き出して警告を出す
- 読み上げは OS 標準の音声合成(Windows: WinRT の SpeechSynthesizer、Mac: `say`)。対応していない OS では無音で代替する
